## Key Decisions Made

1. **`PlatformFullscreen.enter()` returns snapshot** — save-before-enter lives in platform layer, not controller
2. **`requiresStyleSave` capability flag** — macOS/Linux skip style save logic
3. **`_buildExitSnapshot()` merges** — platform snapshot (style) + controller snapshot (position/size)
4. **Borderless frame for macOS** (not native toggleFullScreen) — consistent with media player conventions
