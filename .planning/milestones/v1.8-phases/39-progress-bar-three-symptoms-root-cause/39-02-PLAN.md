| Boundary | Description |
|---|---|
| media_kit Player → project PlayerPort | 异步 duration/position 与 snapshot 进入项目状态，必须绑定当前 source。 |
| PlayerControlsState → widget listenables | notifier identity 与订阅生命周期跨 controls rebuild/replacement 保持一致。 |
