<objective>
**用户故事：作为播放器用户，我想在设置的「通用」页里开关错误卡片、配置并验证日志输出目录，以便按自己的工作流定制反馈且永远知道日志在哪。**

SET-01/02/03 的 UI 收口：把 04-01 的 store、04-02 的协调器接到「通用」tab——设置壳获得选中态架构（`_NavEntry` 从灰显占位变为可交互），`GeneralSettingsContent` 提供开关行与日志路径行（手输防抖校验 + 浏览 + 行内状态 + 有效路径展示）。

Purpose: 这是用户唯一可见的入口层；此前所有计划（store/链/协调器/门控）都在本计划变成可操作的界面。
Output: 设置壳选中态、通用内容组件、l10n key、widget 测试与 Phase 收口质量门。
</objective>
