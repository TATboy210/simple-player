<objective>
**用户故事：作为播放器用户，我希望能一键关闭错误卡片（错误仍被记录），以便在不需要弹卡打扰时保持捕获与日志完整。**

SET-01 的呈现门控：`ErrorCardHost.build` 外层包一个 `ValueListenableBuilder<bool>` 读 `ErrorFeedbackSettings.I.state` 的 `errorCardEnabled`，关闭即 `SizedBox.shrink()` 同帧消失。**零 kernel 改动**（D-05）：reporter FIFO/去重/dismiss、ErrorCaptureSnapshot、error.log 落盘全部原样运转。

Purpose: SET-01 的核心语义（关掉只落盘不弹卡、捕获落盘不受影响、默认开）在本计划锁死；开关的 UI 入口（通用 tab Switch 行）在 04-04 接入同一 store。
Output: 宿主门控一处 + host 测试四用例。
</objective>
