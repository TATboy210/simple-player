## Trust Boundaries

| Boundary | Description |
|---|---|
| PlaybackController/PlayerError → report | live state 与 failed-open target 可在捕获后改变，且路径包含本机敏感目录。 |
| reporter → presentation/effects | 同一报告有 ordinary safe view 与 developer-only full evidence，消费者权限边界不同。 |
| source enricher → reporter | parser/reader 是故障点，不得使 capture 丢失或递归。 |
