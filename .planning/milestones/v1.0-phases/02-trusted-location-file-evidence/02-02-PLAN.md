## Trust Boundaries

| Boundary | Description |
|---|---|
| raw stack text → StackFrame parser | 外部/框架栈可包含 malformed VM line、异步标记及伪造 package path。 |
| parsed frame → local source path | packagePath/file URI 属不可信路径输入，可尝试 traversal 或 sibling-prefix escape。 |
| local source → diagnostic pack | 只允许读取项目根内、指定行附近的小窗口。 |
