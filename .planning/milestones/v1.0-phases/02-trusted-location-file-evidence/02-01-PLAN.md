## Trust Boundaries

| Boundary | Description |
|---|---|
| ErrorReport → formatter | message、stack、路径与标识符可能携带换行和伪造段标题。 |
| Reporter effect → filesystem | 异步写盘可失败、乱序、重入或形成写入洪流。 |
| Diagnostic file → local reader/copy | D-07 明确允许开发者证据含完整本地路径，普通日志/UI 不得误用该输出。 |
