# Plan 18-01: PlayerActions Record Definition + Full Chain Replacement

**Requirement:** ARCH-04, ARCH-05
**Mode:** mvp

## Goal

Define a `PlayerActions` class that bundles all callback parameters, replacing 15+ scattered callbacks in PlayerScreen/ControlsOverlay/ControlBar with a single typed parameter.

| Widget | Callback Params | Data Params | Total |

| PlayerScreen | 10 callbacks | 5 data | 15 |
