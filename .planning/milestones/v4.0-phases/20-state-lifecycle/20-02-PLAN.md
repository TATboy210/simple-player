<objective>
Integrate DiagnosticsBundle into FvpEngine, migrate PlaybackNavigator generation tracking to state machine, add lifecycle methods, and convert KernelAdapter from per-capability to per-method DelegationPolicy.

Purpose: Wire the state machine foundation (Plan 01) into the engine, navigator, and adapter layers. FvpEngine gains bundle injection, recover(), and double-dispose safety. PlaybackNavigator's local _openGeneration is replaced by EngineStateMachine's embedded tracker (D5 single source of truth). KernelAdapter gains per-method routing granularity (Set<String> _migratedMethods) enabling future method-by-method cutover to a new engine.

Output: FvpEngine with DiagnosticsBundle injection + lifecycle methods; PlaybackNavigator delegating generation to state machine; KernelAdapter with per-method DelegationPolicy; PlayerServices wiring updated.
</objective>

**Part A: KernelAdapter per-method DelegationPolicy (D9)**

Modify `kernel_adapter.dart`:

1. **Expand DelegationPolicy** to include per-method tracking:
   - Add field: `final Set<String> migratedMethods;` to DelegationPolicy
   - Keep existing 7 per-capability fields for backward compatibility (they still control default routing)
   - Add constructor: `const DelegationPolicy.perMethod({required this.migratedMethods, KernelMode defaultMode = KernelMode.legacy})` that sets all 7 capability fields to `defaultMode`
   - Keep `DelegationPolicy.all(KernelMode mode)` unchanged

2. **Add helper method to KernelAdapter:**
   - `MediaEngine _targetFor(String method) => _policy.migratedMethods.contains(method) ? _migrated : _legacy;`

3. **Update each method in KernelAdapter** to use per-method routing:
   - For each method (open, play, pause, stop, seekTo, etc.), replace the ternary `_policy.playback == KernelMode.legacy ? _legacy.x : _migrated.x` with `_targetFor('open').open(path)` pattern
   - Method names to use as keys: 'open', 'play', 'pause', 'stop', 'togglePlayPause', 'seekTo', 'setPlaybackRate', 'setRange', 'skipForward', 'skipBack', 'getAudioTracks', 'switchAudioTrack', 'getSubtitleTracks', 'switchSubtitleTrack', 'toggleSubtitle', 'setExternalSubtitle', 'setSubtitleDelay', 'setEqualizer', 'setVideoEffect', 'rotate', 'setAspectRatio', 'setDeinterlace', 'setD3d11SyncEnabled', 'setHardwareDecoding', 'setVolume', 'setMute'
   - For EngineStateView notifiers (state, position, volume, etc.), keep routing via `_policy.stateView` or `_policy.volume` — notifier identity must be preserved (ADAPT-03)
   - The per-method routing applies to **action methods only**, not notifier getters (notifiers are identity-preserving per blocking constraint #6)

4. **Preserve identity-forwarding for notifiers:**
   - All ValueNotifier getters (state, position, duration, volume, isMuted, isBuffering, isSeeking, subtitleText, buffered, aspectRatio, lastError, playbackSpeed, textureId) keep existing `_policy.stateView` / `_policy.volume` routing
   - Only action methods switch to `_targetFor(methodName)`
