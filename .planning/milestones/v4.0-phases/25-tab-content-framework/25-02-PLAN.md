**Create the tabs/ directory and 7 skeleton tab widgets.**

Each tab is a `StatelessWidget` that receives a `PendingSettingsState` reference and renders `SettingRow` skeleton items using the existing components.

**Common pattern for all tabs:**

```dart
/// {TabName} 设置 tab（骨架）— Phase 25 框架占位，后续阶段填充真实功能。
///
/// 接收 [PendingSettingsState] 引用，用户交互通过 pending.update() 存储，
/// 不直接调用 service 方法。
class {TabName}Tab extends StatelessWidget {
  final PendingSettingsState pending;
  const {TabName}Tab({super.key, required this.pending});

  @override
  Widget build(BuildContext context) {
    return AnimatedSectionList(
      children: [
        GlassContainer(
          padding: const EdgeInsets.symmetric(
            horizontal: Tokens.spLg,
            vertical: Tokens.spMd,
          ),
          margin: const EdgeInsets.only(bottom: Tokens.spMd),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              SectionHeader(title: '...', icon: ...),
              SettingRow(title: '...', description: '...', control: ...),
              // more SettingRow items
            ],
          ),
        ),
      ],
    );
  }
}
```

**Key rules for all tabs:**
- Import from `../../shared/` for SettingRow, GlassContainer, etc. (relative to tabs/ directory)
- Import `PendingSettingsState` from `../pending_settings.dart`
- All visual values via Tokens.* — no hardcoded colors, fonts, spacing
- Description text uses `Tokens.textTertiary` color and `Tokens.fontOverline` size (gray small font below label)
- Each tab uses AnimatedSectionList for staggered fade-in
- Each section uses GlassContainer + SectionHeader grouping
- SettingRow receives `control:` widget directly (Switch, Slider, or DropdownButton)
- Do NOT use SettingSwitchRow/SettingSliderRow for skeleton — use raw SettingRow with inline control widgets for maximum flexibility (SettingSwitchRow requires ValueNotifier which doesn't fit pending pattern)

**IMPORTANT:** These are skeleton placeholders. The controls work visually but persist to PendingSettingsState only — no real service calls. The old tab files in lib/ui/dialogs/settings/ are kept untouched for reference.
