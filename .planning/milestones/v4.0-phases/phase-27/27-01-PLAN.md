# Plan 27-01: Responsive Panel Layout & Animation Polish

## Objective
Implement breakpoint-based responsive scaling for the settings panel so it adapts to fullscreen, standard, and small window sizes. Polish open/close animations for smooth 60fps transitions.

## Tasks

### Task 1: Add responsive breakpoint tokens
**Files:** `lib/ui/theme/tokens.dart`
**Read first:** `lib/ui/theme/tokens.dart`

Add settings panel specific breakpoint constants:
- `settingsPanelBreakpointWide = 1200` — wide/fullscreen threshold
- `settingsPanelBreakpointCompact = 800` — small window threshold

Add panel dimension constants:
- `settingsPanelWidthWide = 600.0`, `settingsPanelHeightWide = 480.0`
- `settingsPanelWidthStandard = 500.0`, `settingsPanelHeightStandard = 400.0`
- `settingsPanelWidthCompact = 400.0`, `settingsPanelHeightCompact = 320.0`
- `settingsSidebarWidthWide = 200.0`, `settingsSidebarWidthCompact = 160.0`

**Acceptance:**
- `tokens.dart` contains all new constants as `static const double`
- `flutter analyze` passes with zero errors

### Task 2: Implement responsive panel sizing in SettingsOverlayShell
**Files:** `lib/ui/dialogs/settings/settings_overlay_shell.dart`
**Read first:** `lib/ui/dialogs/settings/settings_overlay_shell.dart`, `lib/ui/theme/tokens.dart`

Replace the current fixed 50% ratio sizing with breakpoint-based logic:
1. Create a `_SettingsPanelLayout` helper that takes `Size windowSize` and returns `(double width, double height, double sidebarWidth)`
2. Logic:
   - `windowSize.width >= Tokens.settingsPanelBreakpointWide` → wide (600×480, sidebar 200)
   - `windowSize.width >= Tokens.settingsPanelBreakpointCompact` → standard (500×400, sidebar 180)
   - else → compact (400×320, sidebar 160)
3. Clamp panel size to 80% of window (existing behavior preserved)
4. Use `MediaQuery.sizeOf(context)` (established pattern)
5. Add `AnimatedSize` wrapper around the panel for smooth transitions when window crosses breakpoints (duration: 300ms, curve: `Curves.easeInOut`)

**Acceptance:**
- Panel renders at correct size for each breakpoint
- Smooth transition when resizing window across breakpoints
- 80% clamp still applies for very small windows
- Existing drag behavior preserved

### Task 3: Polish open/close animation
**Files:** `lib/ui/dialogs/settings/settings_overlay_shell.dart`
**Read first:** `lib/ui/dialogs/settings/settings_overlay_shell.dart`

Current: `AnimatedOpacity` + `AnimatedScale` at 200ms. Enhance:
1. Increase duration to 250ms for smoother feel
2. Add `RepaintBoundary` around the panel content for 60fps isolation
3. Ensure close animation uses `AppleCurves.fullscreenExit` (already present)
4. Ensure open animation uses `AppleCurves.fullscreenEnter` (already present)

**Acceptance:**
- Open animation: Scale 0.95→1.0 + Fade 0→1, 250ms, `fullscreenEnter` curve
- Close animation: Scale 1.0→0.95 + Fade 1→0, 250ms, `fullscreenExit` curve
- `RepaintBoundary` wraps panel content
