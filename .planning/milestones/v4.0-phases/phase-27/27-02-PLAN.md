# Plan 27-02: Settings Panel Integration Tests

## Objective
Create integration tests covering the key user paths through the settings panel: open/close lifecycle, tab switching, setting changes with apply/cancel, and keyboard navigation.

## Tasks

### Task 1: Create integration test file
**Files:** `test/ui/settings_integration_test.dart`
**Read first:** `test/ui/settings_overlay_shell_test.dart`, `test/ui/settings_panel_controller_test.dart`

Create `settings_integration_test.dart` using established patterns:
- `FakePlaybackController implements SettingsPanelPlayback`
- `pumpShell` helper with proper `addTearDown` ordering
- `MediaQuery` override for deterministic sizing

### Task 2: Open/close lifecycle test
**Test:** `integration: open panel shows mask and panel, close cleans up`

1. Create controller + shell
2. Call `controller.open()` → verify mask visible, panel visible, `controller.state.isOpen.value == true`
3. Call `controller.close()` → verify mask gone, panel gone, `controller.state.isOpen.value == false`
4. Verify playback was paused on open and resumed on close

**Acceptance:** Test passes, verifies both UI state and controller state

### Task 3: Tab switching test
**Test:** `integration: tab switching updates content and selected indicator`

1. Open panel
2. Tap tab 2 (EQ) → verify `state.selectedTab.value == 1`, EQ content visible
3. Tap tab 5 (Shortcuts) → verify `state.selectedTab.value == 4`, Shortcuts content visible
4. Use keyboard Right arrow → verify tab advances
5. Use keyboard Left arrow → verify tab goes back

**Acceptance:** Test passes, verifies both click and keyboard tab switching

### Task 4: Setting change with apply/cancel test
**Test:** `integration: setting change, apply persists, cancel reverts`

1. Open panel, navigate to General tab
2. Toggle the dark mode switch → verify `pending.hasChanges == true`
3. Tap Apply → verify `pending.hasChanges == false`, changes committed
4. Toggle switch again → tap Cancel → verify original value restored

**Acceptance:** Test passes, verifies the deferred-apply pattern end-to-end

### Task 5: Keyboard navigation test
**Test:** `integration: ESC and B-key close panel with proper two-step behavior`

1. Open panel, focus on a setting row
2. Press B → verify focus returns to sidebar (first step)
3. Press B again → verify panel closes (second step)
4. Reopen, press ESC → verify panel closes immediately

**Acceptance:** Test passes, verifies two-step B-key and direct ESC behavior
