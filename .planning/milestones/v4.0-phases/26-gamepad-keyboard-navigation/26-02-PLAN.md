**Step 1: Create SpinControl widget (lib/ui/shared/spin_control.dart)**

Build a Steam-style horizontal value selector:

- `SpinControl` StatefulWidget
- Parameters:
  - `options` (List<String>, required) - the selectable values (D-08)
  - `currentIndex` (int, required) - currently selected index
  - `onChanged` (ValueChanged<int>, required) - callback when selection changes
  - `formatValue` (String Function(String)?, optional) - custom value formatter (D-09)
  - `focusKey` (Key?, optional) - for test targeting
- Layout: Row with [left arrow] [animated value] [right arrow]
  - Left arrow: `Icons.chevron_left`, size Tokens.iconMd, color based on boundary (D-03)
  - Right arrow: `Icons.chevron_right`, size Tokens.iconMd, color based on boundary (D-03)
  - Value area: `ClipRect` + `AnimatedSwitcher` with `SlideTransition` for horizontal in/out (D-06)
- Arrow colors:
  - At left boundary (index == 0): left arrow color = Tokens.textTertiary (gray, D-03)
  - At right boundary (index == options.length - 1): right arrow color = Tokens.textTertiary
  - Otherwise: Tokens.textSecondary
- Animation: `AnimatedSwitcher` with `duration: Duration(milliseconds: 200)` (D-07)
  - Custom transition builder: `SlideTransition` with `Tween<Offset>(begin: Offset(direction, 0), end: Offset.zero)`
  - `direction` = +1 for right (new value entering from right), -1 for left (new value entering from left)
- Value display: `Text(formatValue?.call(options[currentIndex]) ?? options[currentIndex])`
  - Style: `TextStyle(color: Tokens.textPrimary, fontSize: Tokens.fontBody)`
- Interaction: `GestureDetector` on left/right arrow areas
  - Left arrow tap: `onChanged(currentIndex - 1)` if not at boundary
  - Right arrow tap: `onChanged(currentIndex + 1)` if not at boundary
- Focus integration: Wrap in `FocusableSettingRow` (from Plan 01) so it gets focus border + hover
- Keyboard handling within the widget: when focused, ArrowLeft/Right trigger value change (D-10)
  - Use `Focus` with `onKeyEvent` to handle ArrowLeft/ArrowRight directly within SpinControl
  - ArrowLeft: decrement index if not at boundary
  - ArrowRight: increment index if not at boundary
  - Return `KeyEventResult.handled` to prevent bubbling to shell's _handleKeyEvent
- Size: fixed height 36px, arrows 32px wide each, value area fills remaining width
- Doc comments on class and all parameters in Chinese+English style
