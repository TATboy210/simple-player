# Cross-Platform Window Management — Project Initialized

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| macOS NSWindow off-main-thread | Cocoa API calls on platform thread cause random crashes | blocking | Always dispatch NSWindow calls via dispatch_async(dispatch_get_main_queue()) |
| Wayland client positioning | setPosition() is a no-op on Wayland by design | blocking | Detect Wayland at runtime, skip position persistence, save size only |
| macOS fullscreen polling | toggleFullScreen uses animated Space, immediate isFullscreen check returns stale state | blocking | Use NSWindowDelegate callbacks, not polling |
