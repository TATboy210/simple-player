## Key Design Decisions

- WindowService 是 singleton（不是 WindowState）
- UI 通过 `WindowService.instance.state` 访问状态
- Resize 状态移到 UI 层（ResizeNotifier），WindowState 不管
- 删除：SharedPreferences 持久化、geometry clamping、resize debounce、AspectRatioService fullscreen
- `interaction` enum → `ResizeNotifier.instance`（ValueNotifier<bool>）
- `alwaysOnTop` 保留（custom_title_bar pin 按钮使用）
