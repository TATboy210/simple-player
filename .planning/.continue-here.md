## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 静默失败 | EngineStateMachine assert-only 非法转换（release 无效），静默忽略错误 | blocking | Phase 20 换 Result.err + KernelLogger 警告（STATE-03） |
| 跨提交拆分单例重构 | R2-5 删 _instance 留静态方法致构建失败 | blocking | MemoryMonitor 单例→实例在**一个原子提交**内完成 shim+重写+删 shim（MEM-04, Phase 19） |
| ValueNotifier 重新包装 | 适配层包装 notifier 致 ValueListenableBuilder 监听器脱钩，UI 冻结 | blocking | 适配层转发活动引擎同一 notifier 实例（ADAPT-03, Phase 16） |
| 一次性 big-bang 替换内核 | 适配层不存在就重写状态机，替换引擎成禁断 swap | blocking | 适配层须先于状态重写存在，构建顺序 P15契约→P16适配→P17+... |
| 永久 god-adapter 层 | 兼容替换诱发过度工程化，适配层膨胀 | blocking | 尺寸预算合计 < 旧 FvpEngine + red-team 挑战范围蔓延（ADAPT-05, Phase 16） |
| logger 误解为新建门面 | 误把 KernelLogger 当全新门面从零写 | advisory | 它是替换迁移（保留 log*.w() 调用形状），非新建；内核永不 import package:logger（Phase 17） |
| 主会话直产绕过分类器宕机 | glm-5.2 间歇宕机卡 Agent/Bash，roadmapper 无法 spawn | advisory | read-only+Write/Edit 不受影响；主会话已持输入可直产。本会话已用此法完成路线图。 |

## Critical Anti-Patterns (do NOT repeat these)

- **静默失败**：EngineStateMachine assert-only 非法转换 → Phase 20 换 Result.err + KernelLogger 警告。
- **跨提交拆分单例重构**：R2-5 教训 → MemoryMonitor 单例→实例一个原子提交内 shim+重写+删 shim（Phase 19）。
- **ValueNotifier 重新包装**：适配层包装致 UI 冻结 → 转发同一 notifier 实例（Phase 16）。
- **一次性 big-bang 替换**：适配层须先于状态重写存在（构建顺序硬约束）。
- **永久 god-adapter**：尺寸预算合计 < 旧 FvpEngine + red-team 挑战范围蔓延（Phase 16）。
- **logger 误解为新建门面**：是替换迁移（保留调用形状），非新建（Phase 17）。
- **同一文件多 Edit 并行致竞态覆盖**：本会话教训 → 须串行 Edit 或用 Write 整体替换。
