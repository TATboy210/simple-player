## 已完成工作

### R1: 控制栏按钮不可点击 [P0] — ✅ 修复完成

**根因：** `BackdropFilter` 包裹整个 ControlBar（含按钮），在 Windows 桌面端干扰 hit test。

**证据：** commit c14f467 中 `enableBlur: false, // TODO: 临时禁用模糊测试点击` — 开发者之前已发现此问题。

**修复方案：** 将 BackdropFilter 从按钮层分离 — 背景层（毛玻璃装饰）和交互层（按钮/进度条）用 Stack 分层。

**修改文件：**
- `lib/ui/player/control_bar.dart` — `_buildBlur(Widget content)` → `_buildBlur(Widget background, Widget foreground)`
- `test/golden/goldens/control_bar_*.png` — golden 更新（布局结构变化）

**测试结果：**
- button_hit_test: 5/5 通过
- control_bar_test: 13/13 通过
- 全量测试: 771/771 通过

**待验证：** 实机 `flutter run -d windows` 确认按钮可点击
