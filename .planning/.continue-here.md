# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: Rust toolchain PATH — `rustc`/`cargo` not in default PATH, must use `export PATH="$HOME/.cargo/bin:$PATH"` before any cargo/rustup command
- [ ] CONSTRAINT: libmpv 链接路径 — cargokit 在临时目录运行 cargo，`.cargo/config.toml` 不生效，必须用 `build.rs` 的 `cargo:rustc-link-search`
- [ ] CONSTRAINT: libmpv DLL 部署 — `libmpv-2.dll` 必须复制到 `build/windows/x64/runner/Debug/`
- [ ] CONSTRAINT: FRB 无法生成 `Arc<Mutex<Mpv>>` 参数 — 用 `OnceLock` 全局 handle 绕过，事件循环和命令方法共享同一 handle
- [ ] CONSTRAINT: FRB 扫描 `rust/src/api/` — 内部模块（event_loop.rs, render.rs）必须放在 api/ 外面，否则 FRB 会生成不需要的绑定
- [ ] CONSTRAINT: libmpv2 wrapper 不暴露 SW render — 必须用 libmpv2-sys FFI 直接调用 mpv_render_context_create/render，SW 常量值 17-20

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| .cargo/config.toml for cargokit | cargokit runs cargo from temp dir, config.toml ignored | blocking | Use build.rs `cargo:rustc-link-search` |
| FRB + complex generics as params | `Arc<Mutex<Mpv>>` in function params → codegen fails | blocking | Use global OnceLock, keep FRB-facing types simple |
| FRB scanning internal modules | Internal helpers in api/ get unwanted bindings | blocking | Put internal modules outside api/ directory |
| libmpv2 wrapper for SW render | RenderParamApiType only has OpenGl, no SW variant | blocking | Use libmpv2-sys raw FFI for SW render params |
