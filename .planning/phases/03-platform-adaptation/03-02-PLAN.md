  <action>
    扩展 fullscreen_window 的 macOS 插件，添加 NSWindowDelegate 回调支持 (D-P09)。

    **ObjC 修改 (FullscreenWindowPlugin.h):**
    - 修改接口声明: `@interface FullscreenWindowPlugin : NSObject <FlutterPlugin, NSWindowDelegate>`
    - 添加属性: `@property (nonatomic, strong) FlutterMethodChannel *channel;`

    **ObjC 修改 (FullscreenWindowPlugin.m):**

    1. `registerWithRegistrar:` 方法中:
       - 保存 channel 引用到 `instance.channel = channel;`
       - 获取 mainWindow 并设置 delegate: `NSWindow *window = [NSApp mainWindow]; window.delegate = instance;`
       - 注意: 如果 mainWindow 为 nil，延迟到首次 setFullScreen 调用时设置

    2. 添加 NSWindowDelegate 方法:
       ```objc
       - (void)windowDidEnterFullScreen:(NSNotification *)notification {
           [self.channel invokeMethod:@"onFullScreenChanged" arguments:@{@"isFullScreen": @YES}];
       }

       - (void)windowDidExitFullScreen:(NSNotification *)notification {
           [self.channel invokeMethod:@"onFullScreenChanged" arguments:@{@"isFullScreen": @NO}];
       }
       ```

    3. `handleMethodCall:result:` 中:
       - 在 `setFullScreen` 处理前，确保 window.delegate 已设置
       - 添加 `getFullScreenState` 方法: 查询 `window.styleMask & NSWindowStyleMaskFullScreen` 返回当前状态

    **Dart 修改 (fullscreen_window_platform_interface.dart):**
    - 添加: `Stream<bool> get onFullScreenChanged => const Stream.empty();`
    - 添加: `Future<bool> isFullScreen() async => false;`

    **Dart 修改 (fullscreen_window_method_channel.dart):**
    - 添加 `EventChannel` 或使用 `MethodChannel.setMethodCallHandler` 接收原生回调
    - 推荐方案: 在构造函数中设置 `methodChannel.setMethodCallHandler(_handleMethod)`
    - `_handleMethod` 处理 `onFullScreenChanged` 方法: 解析 `isFullScreen` 参数，添加到 StreamController
    - 暴露 `Stream<bool> onFullScreenChanged` 流
    - 添加 `isFullScreen()`: 调用原生 `getFullScreenState` 方法

    **关键注意事项:**
    - NSWindowDelegate 回调在 AppKit 主线程执行，MethodChannel invokeMethod 是线程安全的
    - toggleFullScreen: 是异步动画 (~0.7s)，delegate 回调在动画完成后触发
    - 确保 window.delegate 不被 ARC 释放 — plugin 实例持有强引用
    - 如果用户通过系统快捷键 (Ctrl+Cmd+F) 或绿色按钮触发动画，delegate 同样会触发回调

  <action>
    创建 `lib/kernel/bridge/platform/macos_fullscreen_driver.dart` — macOS 原生全屏驱动。

    **类设计:**

    `MacosFullscreenDriver` implements `FullscreenDriver`。

    构造函数注入:
    ```dart
    MacosFullscreenDriver({
      FullScreenWindowPlatform? plugin,
      WindowManager? wm,
    }) : _plugin = plugin ?? fullScreenWindow,
         _wm = wm ?? windowManager;
    ```

    **内部组件:**
    - `_plugin: FullScreenWindowPlatform` — fullscreen_window 插件 (全屏操作)
    - `_wm: WindowManager` — window_manager (其他窗口操作: getPosition/getSize/setBounds/maximize/restore/focus/isMaximized/isMinimized)
    - `_stateStreamSub: StreamSubscription<bool>?` — 监听原生回调流
    - `_onNativeCallback: void Function(int windowId, bool isFullscreen)?` — 通知 Adapter 的回调

    **原生回调桥接 (D-P09):**
    - 设置 setter: `set onNativeStateChanged(void Function(int, bool)? callback)`
    - 构造函数中订阅 `_plugin.onFullScreenChanged` 流 (如果可用):
      ```dart
      _stateStreamSub = _plugin.onFullScreenChanged?.listen((isFullscreen) {
        _onNativeCallback?.call(0, isFullscreen); // windowId=0 单窗口
      });
      ```

    **方法实现:**

    1. `enterFullscreen({int displayId = 0})`:
       - 调用 `_plugin.setFullScreen(true)` (D-P10: 使用原生 toggleFullScreen: 动画)
       - 不等待动画完成 — 状态确认由 Adapter 的三级确认链处理

    2. `leaveFullscreen()`:
       - 调用 `_plugin.setFullScreen(false)`

    3. `queryFullscreen()`:
       - 优先调用 `_plugin.isFullScreen()` 查询真实状态
       - 如果插件方法不可用，回退到 `_wm.isFullScreen()`

    4. `getPosition()` / `getSize()` / `setBounds()` / `maximize()` / `restore()` / `focus()` / `isMaximized()` / `isMinimized()`:
       - 全部委托给 `_wm` (window_manager)

    5. `capabilities()`:
       - 返回 `FullscreenCapability(supportsFullscreen: true, supportsMultiWindow: false, supportsMultiDisplay: true, supportsExclusive: false, requiresUserGesture: false, platformNotes: 'Native macOS fullscreen animation (green button). Confirmation via NSWindow delegate callback. Transition time ~700ms.')`

    6. `dispose()`:
       - 取消 `_stateStreamSub` 订阅

    **单元测试 (test/platform/macos_fullscreen_driver_test.dart):**

    MockFullScreenWindowPlatform: 记录 setFullScreen 调用，可控 isFullScreen 返回值，可控 onFullScreenChanged 流。
    MockWindowManager: 记录所有调用。

    测试用例:
    - enterFullscreen 调用 plugin.setFullScreen(true)
    - leaveFullscreen 调用 plugin.setFullScreen(false)
    - queryFullscreen 委托给 plugin.isFullScreen()
    - 原生回调触发时通知 onNativeStateChanged
    - capabilities 返回 macOS 特有能力值
    - window 管理方法委托给 window_manager
    - dispose 取消流订阅
