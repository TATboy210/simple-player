  <action>
    创建 `lib/kernel/bridge/win32/win32_fullscreen_ffi.dart` — Win32 全屏操作 FFI 绑定。

    设计模式: 参考 win32_display_enumerator.dart 的静态工具类 + 实例适配器模式。

    **结构:**

    1. Win32 结构体定义 (per D-P05):
       - `_RECT` (left/top/right/bottom Int32) — 复用与 display_enumerator 相同的结构
       - `_WINDOWPLACEMENT` (length/flags/showCmd Uint32, ptMinPosition/ptMaxPosition _POINT, rcNormalPosition _RECT)
       - `_POINT` (x/y Int32)
       - `_MONITORINFO` (cbSize Uint32, rcMonitor/rcWork _RECT, dwFlags Uint32)

    2. Win32 常量:
       - `_gwlStyle = -16`, `_gwlExStyle = -20`
       - `_wsCaption = 0x00C00000`, `_wsThickframe = 0x00040000` (D-P06: WS_THICKFRAME 剥离)
       - `_wsExTopmost = 0x00000008`
       - `_hwndTopmost = -1`, `_hwndNotopmost = -2` (D-P08: TopMost 清理)
       - `_swpNomove = 0x0002`, `_swpNosize = 0x0001`, `_swpNoownerzorder = 0x0200`, `_swpFramechanged = 0x0020`
       - `_monitorDefaultToNearest = 2`

    3. Win32 函数签名 (typedef Native/Dart 对):
       - `GetWindowLongW` / `SetWindowLongW` — 窗口样式操作
       - `SetWindowPos` — 窗口位置/尺寸/Z-order 设置
       - `SetForegroundWindow` / `SetFocus` — 焦点恢复 (D-P07)
       - `IsWindowVisible` / `IsIconic` — 焦点恢复安全护栏 (D-P07)
       - `IsWindow` — HWND 有效性检查 (T-03-01 安全)
       - `IsZoomed` — 全屏/最大化状态查询
       - `MonitorFromWindow` / `GetMonitorInfoW` — 显示器信息获取
       - `GetWindowPlacement` / `SetWindowPlacement` — 窗口位置恢复
       - `FindWindowW` — 获取 Flutter 窗口 HWND

    4. DLL 加载 + 函数查找:
       - `final DynamicLibrary _user32 = DynamicLibrary.open('user32.dll');`
       - 所有函数用 `_user32.lookupFunction<Native, Dart>()` 查找
       - 与 win32_display_enumerator.dart 共享同一个 _user32 实例不可行（跨文件），各自独立加载

    5. `Win32FullscreenApi` 静态工具类:
       - 所有方法为 static
       - `getFlutterHwnd()` — 查找 FLUTTER_RUNNER_WIN32_WINDOW 窗口句柄
       - `getWindowLong/setWindowLong` — 样式读写
       - `setWindowPos` — 窗口位置设置
       - `setForegroundWindow/setFocus` — 焦点恢复
       - `isWindowVisible/isIconic/isWindow/isZoomed` — 状态查询
       - `monitorFromWindow/getMonitorRect` — 显示器信息
       - `getWindowPlacement/setWindowPlacement` — 窗口位置保存/恢复
       - 每个方法内部 try-catch，失败时 debugPrint 错误并返回安全默认值

    **关键实现细节:**
    - FFI 内存管理: calloc 分配的结构体必须在 finally 块中 free (参考 win32_display_enumerator.dart 第 199 行)
    - `getMonitorRect()` 返回 `({int left, int top, int right, int bottom})` record 类型
    - `_getDevicePixelRatio()` 复用 `PlatformDispatcher.instance.views.first.devicePixelRatio` 模式

  <action>
    创建 `lib/kernel/bridge/platform/windows_fullscreen_driver.dart` — Windows 原生全屏驱动。

    **类设计:**

    `WindowsFullscreenDriver` implements `FullscreenDriver`，可选注入 `Win32FullscreenApi` mock (per D-P05 扩展现有逻辑)。

    构造函数:
    ```dart
    WindowsFullscreenDriver({Win32FullscreenApi? api}) : _api = api ?? Win32FullscreenApi();
    ```

    **内部状态:**
    - `_savedStyle: int = 0` — 进入全屏前的 GWL_STYLE 快照
    - `_savedExStyle: int = 0` — 进入全屏前的 GWL_EXSTYLE 快照
    - `_savedPlacement: Pointer<_WINDOWPLACEMENT>?` — 进入全屏前的窗口位置快照
    - `_isFullscreen: bool = false` — 内部全屏状态跟踪

    **方法实现:**

    1. `enterFullscreen({int displayId = 0})` (D-P06):
       - 获取 HWND: `_api.getFlutterHwnd()`，为 0 时 debugPrint + return
       - 保存当前样式: `_savedStyle = _api.getWindowLong(hwnd, GWL_STYLE)`
       - 保存扩展样式: `_savedExStyle = _api.getWindowLong(hwnd, GWL_EXSTYLE)`
       - 保存窗口位置: `_api.getWindowPlacement(hwnd, placementPtr)`
       - 剥离 WS_THICKFRAME + WS_CAPTION: `_api.setWindowLong(hwnd, GWL_STYLE, _savedStyle & ~(WS_CAPTION | WS_THICKFRAME))`
       - 设置 WS_EX_TOPMOST: `_api.setWindowLong(hwnd, GWL_EXSTYLE, _savedExStyle | WS_EX_TOPMOST)`
       - 获取显示器区域: `_api.getMonitorRect(_api.monitorFromWindow(hwnd, MONITOR_DEFAULTTONEAREST))`
       - 覆盖整个显示器: `_api.setWindowPos(hwnd, HWND_TOPMOST, rc.left, rc.top, width, height, SWP_NOOWNERZORDER | SWP_FRAMECHANGED)`
       - `_isFullscreen = true`

    2. `leaveFullscreen()` (D-P06 + D-P07 + D-P08):
       - 获取 HWND，为 0 时 return
       - 恢复窗口样式 (D-P06): `_api.setWindowLong(hwnd, GWL_STYLE, _savedStyle)`
       - 恢复扩展样式: `_api.setWindowLong(hwnd, GWL_EXSTYLE, _savedExStyle)`
       - 清理 TopMost (D-P08): `_api.setWindowPos(hwnd, HWND_NOTOPMOST, 0, 0, 0, 0, SWP_NOMOVE | SWP_NOSIZE | SWP_NOOWNERZORDER | SWP_FRAMECHANGED)`
       - 恢复窗口位置: `_api.setWindowPlacement(hwnd, _savedPlacement)`
       - 强制 Flutter 布局刷新: `_api.setWindowPos(hwnd, 0, ..., SWP_NOZORDER | SWP_NOACTIVATE | SWP_FRAMECHANGED)` (参考 fullscreen_window_plugin.cpp 第 55 行)
       - 焦点恢复 (D-P07): `if (_api.isWindowVisible(hwnd) && !_api.isIconic(hwnd)) { _api.setForegroundWindow(hwnd); _api.setFocus(hwnd); }`
       - `_isFullscreen = false`

    3. `queryFullscreen()`:
       - 优先使用 `IsZoomed(hwnd)` 查询真实状态
       - 回退到 `_isFullscreen` 内部状态
       - HWND 无效时返回 `_isFullscreen`

    4. `getPosition()` / `getSize()`:
       - 通过 `_api.getWindowPlacement(hwnd)` 获取 rcNormalPosition
       - 转换为 Flutter 逻辑像素 (除以 devicePixelRatio，参考 win32_display_enumerator.dart _rectToFlutter)

    5. `setBounds(Offset? position, Size? size)`:
       - 通过 `_api.setWindowPos()` 设置窗口位置和/或尺寸
       - 转换逻辑像素为物理像素 (乘以 devicePixelRatio)

    6. `maximize()` / `restore()` / `focus()`:
       - 委托给 window_manager 或通过 Win32 API 实现
       - 注意: maximize 通过 `ShowWindow(hwnd, SW_MAXIMIZE)` 实现

    7. `isMaximized()`:
       - 使用 `_api.isZoomed(hwnd)` 查询

    8. `isMinimized()`:
       - 使用 `_api.isIconic(hwnd)` 查询

    9. `capabilities()`:
       - 返回 `FullscreenCapability(supportsFullscreen: true, supportsMultiWindow: false, supportsMultiDisplay: true, supportsExclusive: false, requiresUserGesture: false, platformNotes: 'Win32 FFI: WS_THICKFRAME removal, focus recovery, TopMost cleanup')`

    **代码规范:**
    - 所有公开方法和类必须有 `///` doc comment (CLAUDE.md Comment Policy)
    - 使用 `debugPrint()` 记录错误，不使用 print
    - FFI 内存在 finally 块中释放
    - 中文注释可接受 (项目约定)
