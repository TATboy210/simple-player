## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tab arrow click → controller tab state | End-cap clicks must route through the same controller.prevTab/nextTab path as keyboard arrows, not introduce a second tab-selection state. |
| Mouse Listener → InputModeDetector | Pointer events from the panel surface feed the detector heuristic; non-mouse kinds must be filtered. |
| Shortcuts tab toggle → InputModeDetector | The toggle must not steal focus from the KeyboardListener recording state. |
