## Phase Goal

Add a gradient transition strip above the control bar that fades from transparent (top) to the control bar's background color (bottom). This eliminates the hard visual edge between video content and the glass control bar, creating a smooth visual bridge.

---

## Gradient Strip Specification

### Dimensions

| Property | Value | Source |
|----------|-------|--------|
| Height | 60px | New token `gradientStripHeight` |
| Horizontal margin | 24px each side | `Tokens.controlBarMarginH` |
| Bottom edge | Flush against control bar top edge | No gap |
| Width | Full width minus margins | Same as control bar |

### Gradient Definition

**Direction:** Top-to-bottom (`begin: Alignment.topCenter, end: Alignment.bottomCenter`)

**Playing state stops:**
```
0.0  → Colors.transparent          (top edge — fully transparent)
1.0  → Tokens.controlBarBg         (bottom edge — #080A10 @ 45% alpha)
```

**Idle state stops:**
```
0.0  → Colors.transparent          (top edge — fully transparent)
1.0  → Tokens.controlBarBgIdle     (bottom edge — #080A10 @ 22% alpha)
```

### Animation

- Gradient bottom color transitions smoothly with the control bar's idle/playing state change (same 150ms easeInOut via AnimatedContainer or implicit animation)
- Strip opacity is synced to `_autoHide.opacity` — fades in/out with the control bar
- No independent animation timing

### Hit Testing

- Strip is non-interactive (no tap/gesture handling)
- Uses `HitTestBehavior.translucent` or excluded from hit test — pointer events pass through to video surface below
- The strip does NOT affect `_isInControlBar()` boundary detection in ControlsOverlay

### Widget Tree Placement

In `ControlsOverlay.build()`, the gradient strip is inserted as a new `Positioned` widget in the Stack, positioned ABOVE the control bar:

```
Stack (existing)
├── Positioned: OsdOverlay (existing, top)
├── Positioned: GradientStrip (NEW — between OSD and ControlBar)
│   bottom: Tokens.controlBarMarginBottom + Tokens.controlBarHeight
│   left:   Tokens.controlBarMarginH
│   right:  Tokens.controlBarMarginH
│   height: Tokens.gradientStripHeight (60px)
│   child:  FadeTransition(opacity: _autoHide.opacity, child: gradient)
├── Positioned: ControlBar (existing, bottom)
├── Positioned: ErrorBanner (existing, above OSD)
```

The gradient strip sits directly above the control bar with zero gap. Its bottom edge aligns with the control bar's top edge (`controlBarMarginBottom + controlBarHeight`).

## New Tokens

Add to `lib/ui/theme/tokens.dart`:

```dart
// ── 渐变过渡带 ──

```

No new color tokens needed — the gradient reuses existing `controlBarBg` and `controlBarBgIdle`.

## Interaction Contract

| Trigger | Response |
|---------|----------|
| Control bar fades in | Gradient strip fades in (same opacity animation) |
| Control bar fades out | Gradient strip fades out (same opacity animation) |
| Idle/playing state change | Gradient bottom color transitions (150ms easeInOut) |
| Mouse hover on strip area | No response (passthrough to video surface) |
| Window resize | Strip resizes with control bar (same margins) |
| Fullscreen toggle | Strip adapts (same margins, same behavior) |

---

## Performance Considerations

- The gradient strip is a simple `Container` with `BoxDecoration(gradient: LinearGradient(...))` — no `BackdropFilter`, no GPU readback
- Uses `FadeTransition` for opacity (off-main-thread interpolation)
- No `AnimatedBuilder` needed unless the gradient colors change dynamically (they don't in v1.4)
- Add `RepaintBoundary` around the strip to isolate repaint region from control bar repaints
