**Document `playback_navigator.dart` (DOC-56) — navigation + concurrency guard**
- Module-level overview: index-based navigation with openGeneration guard for rapid track switching
- Class-level doc: explains playIndex/playNext/playPrevious, openGeneration pattern for discarding stale async requests
- Method doc on `playIndex()`: the full open flow (validate path -> open engine -> resume position -> detect subtitles -> play)

- Module-level overview: monitors engine state changes for auto-advance on completion, breakpoint saving on pause, and settings restoration on init
- Class-level doc: explains observer pattern, three responsibilities (init/restore, state monitoring, dispose/save)

- Method doc on `_onStateChanged()`: the state machine (paused -> save breakpoint, completed -> auto-advance or loop)

- Inline why-comment on `_loadPlaylistForMigration()` explaining: background loading for history migration, not for state restoration
- Inline why-comment on `unawaited()` calls in dispose explaining: fire-and-forget saves, errors logged but not blocking

**Document `auto_advance_policy.dart` (DOC-48) — strategy pattern**
- Module-level overview: strategy pattern for auto-advance behavior based on play mode (loopSingle vs loopAll/shuffle)

- Method doc on `_replayIndex()`: error handling with onError callback
- Method doc on `_autoAdvance()`: delegates to navigator.playNext()
- Inline why-comment on `unawaited()` explaining: fire-and-forget async advance, errors caught internally

**Document `player_error_bus.dart` (DOC-49) — sealed class + broadcast stream**

- Method doc on `dispose()`: closes the stream controller
- Inline why-comment on sealed class choice explaining: enables exhaustive switch in UI error handling

**Document `playback_contract.dart` (DOC-50) — interface decoupling**
