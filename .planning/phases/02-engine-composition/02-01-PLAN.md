   - `void applyDefaults()` that calls all 5 setProperty calls in order:
     - `_player.setProperty('d3d11.sync.cpu', DisplayConfig.d3d11SyncMode());` (CPU/GPU sync via DisplayConfig singleton)
     - `_player.setProperty('video.decoders', defaultVideoDecoders);` (hardware-first decoder chain)
     - `_player.setProperty('avcodec.threads', _ffmpegDecoderThreads);` (memory optimization)
     - `_player.setProperty('videoout.buffer_frames', _maxBufferFrames);` (memory optimization)
     - `_player.setProperty('reader.starts_with_key', '1');` (discard pre-keyframe packets)
   - End with `log.d('D3D11Configurator: defaults applied');`

5. Do NOT change the existing setSyncEnabled() or setHardwareDecoding() methods. They remain as-is for runtime configuration.

6. Do NOT change the class constructor — it already takes `mdk.Player _player` which applyDefaults() uses.
