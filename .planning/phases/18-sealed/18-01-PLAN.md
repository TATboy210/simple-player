    **Step 1: Add ErrorContext class** (per D1, D3, D11) at the top of player_error.dart, before the PlayerError sealed class.

    ErrorContext is a plain Dart class with:
    - `final String? action` — operation name (e.g., 'open', 'play', 'seek')
    - `final int? generation` — open() counter for correlating to specific open request
    - `final String? path` — file path or URL
    - `final DateTime timestamp` — error time (D3: default DateTime.now(), overridable via named param)
    - `final String? module` — module name (e.g., 'FvpEngine', 'MediaOpener')
    - `final StackTrace? callbackStackTrace` — mdk callback thread stack, only filled during cross-thread marshalling (D11)
    - Constructor: `ErrorContext({this.action, this.generation, this.path, DateTime? timestamp, this.module, this.callbackStackTrace}) : timestamp = timestamp ?? DateTime.now();`
    - `Map<String, Object?> toMap()` method that serializes all non-null fields to a Map (camelCase keys). timestamp always included as ISO 8601 string. callbackStackTrace included as toString() when non-null. Use `if (field != null) 'key': field` pattern for optional fields.
    - Bilingual doc comments on class and each field (Chinese intent + English contract per project convention).

    **Step 2: Extend sealed PlayerError** (per D1, D4, D7):
    - Remove `const` from the `PlayerError()` constructor (ErrorContext contains DateTime.now() which is non-const, per research Pitfall 4).
    - Add `ErrorContext? context` field (optional, backward compatible per D1). NOT abstract — concrete nullable field with default null.
    - Add `bool get isFatal` abstract getter (per D4).
    - Add `String get l10nKey` abstract getter (per D7).

    **Step 3: Add recoverable marker to each enum** (per D5):
    - `FileErrorCode`: pathEmpty(recoverable: true), fileNotFound(recoverable: true), pathTraversal(recoverable: false)
    - `CodecErrorCode`: unsupportedFormat(recoverable: true), decodeFailed(recoverable: true), codecUnsupported(recoverable: true)
    - `PlaybackErrorCode`: playFailed(recoverable: true), seekFailed(recoverable: true), textureFailed(recoverable: false), openTimeout(recoverable: true)
    - `NetworkErrorCode`: timeout(recoverable: true), connectionLost(recoverable: true)
    - Each enum gains `final bool recoverable; const {required this.recoverable};` (per D5).
    - Add doc comment on each enum: `/// 错误码注册表 — append-only, 现有码永不重命名/删除 (D6).`

    **Step 4: Update each subclass** (per D4, D7):
    - **FileError**: Remove `const` from constructor. Add optional `ErrorContext? context` named param. Implement `isFatal` as `!code.recoverable`. Implement `l10nKey` as `'error.file.${code.name}'`. Add `context` field assignment in constructor body.
    - **CodecError**: Same pattern. `l10nKey` = `'error.codec.${code.name}'`.
    - **PlaybackError**: Same pattern. `l10nKey` = `'error.playback.${code.name}'`.
    - **NetworkError**: Same pattern. `l10nKey` = `'error.network.${code.name}'`.
    - **UnknownError**: No code enum. `isFatal` returns `false` (always recoverable per research Open Q4). `l10nKey` returns `'error.unknown'`. Remove `const` from constructor. Add optional `ErrorContext? context` named param.

    - Test ErrorContext construction with explicit timestamp.
    - Test ErrorContext.toMap() serializes non-null fields, omits null fields.
    - Test ErrorContext.toMap() includes callbackStackTrace when non-null.
    - Test each subclass: isFatal returns correct value based on code.recoverable.
    - Test each subclass: l10nKey returns correct format string.
    - Test UnknownError: isFatal is false, l10nKey is 'error.unknown'.
    - Test ErrorContext is optional (errors without context still work).
    - Test each enum value has recoverable marker defined.
    - Update existing `const` error constructions to remove `const` keyword (since constructors are no longer const).
