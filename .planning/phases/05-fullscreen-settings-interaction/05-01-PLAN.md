# Plan 05-01: Fullscreen-Aware Settings Panel Positioning

## Objective

Make the SettingsPanel respond correctly to fullscreen mode transitions: reposition to center on enter, return to windowed position on exit, intercept ESC in fullscreen, and disable dragging in fullscreen. All 12 locked decisions (D-01 through D-12) are implemented.

**2. Add mode change listener in initState (D-09)**

**3. Wrap build() in PopScope + Focus for ESC interception (D-04, D-12)**

Wrap the entire `build()` return value in:
- `PopScope(canPop: false, child: ...)` — prevents Navigator.maybePop from dismissing dialog on ESC
- `Focus(autofocus: true, onKeyEvent: _handleEscape, child: ...)` — intercepts ESC at dialog level

Create `_handleEscape` method:
```dart
KeyEventResult _handleEscape(FocusNode node, KeyEvent event) {
  if (event is! KeyDownEvent) return KeyEventResult.ignored;
  if (event.logicalKey == LogicalKeyboardKey.escape) {
    Navigator.of(context).pop(); // close panel
    return KeyEventResult.handled; // stop propagation to outer KeyboardHandler
  }
  return KeyEventResult.ignored;
}
```

**4. Replace static Align with AnimatedAlign + ValueListenableBuilder (D-01, D-03, D-05, D-06, D-08, D-11)**

Replace the current positioning structure (lines ~464-592):
```dart
ValueListenableBuilder<Offset>(
  valueListenable: _offset,
  builder: (context, offset, panel) =>
      Transform.translate(offset: offset, child: panel),
  child: Align(
    alignment: Alignment.topLeft,
    child: Padding(
      padding: const EdgeInsets.only(left: 80, top: 48),
      child: GlassContainer(...),
    ),
  ),
)
```

With the new fullscreen-aware structure:
```dart
ValueListenableBuilder<WindowMode>(
  valueListenable: widget.windowService.mode,
  builder: (context, mode, _) {
    final isFullscreen = mode.isFullscreen;
    return AnimatedAlign(
      alignment: isFullscreen ? Alignment.center : Alignment.topLeft,
      duration: const Duration(milliseconds: Tokens.durationSlide),
      curve: Curves.easeOutCubic,
      child: Padding(
        padding: isFullscreen
            ? EdgeInsets.zero
            : const EdgeInsets.only(left: 80, top: 48),
        child: ValueListenableBuilder<Offset>(
          valueListenable: _offset,
          builder: (context, offset, panel) =>
              Transform.translate(offset: offset, child: panel),
          child: GlassContainer(
            // ... existing GlassContainer with SizedBox 600x480
          ),
        ),
      ),
    );
  },
)
```

Key behaviors:
- `AnimatedAlign` with `alignment` switching between `Alignment.center` (fullscreen) and `Alignment.topLeft` (windowed) provides smooth transition (D-01, D-03, D-05, D-08)
- `Duration(milliseconds: Tokens.durationSlide)` = 300ms with `Curves.easeOutCubic` for smooth feel
- Padding switches: `EdgeInsets.zero` in fullscreen, `EdgeInsets.only(left: 80, top: 48)` in windowed (D-06)
- `_offset` Transform.translate sits INSIDE AnimatedAlign so drag offset is relative to aligned position

**5. Disable drag in fullscreen (D-06, D-11)**

In the title bar GestureDetector (the drag handle area), conditionally disable drag callbacks based on `isFullscreen`. The `isFullscreen` value is available from the `ValueListenableBuilder<WindowMode>` added in step 4 — capture it in the builder scope and pass to the title bar area.

Replace the current drag GestureDetector:
```dart
GestureDetector(
  onPanStart: (_) {},
  onPanUpdate: (d) {
    _offset.value += d.delta;
  },
  child: Container(/* title bar */),
)
```

With:
```dart
GestureDetector(
  onPanStart: isFullscreen ? null : (_) {},
  onPanUpdate: isFullscreen ? null : (d) {
    _offset.value += d.delta;
  },
  child: Container(/* title bar */),
)
```

Setting `onPanStart`/`onPanUpdate` to `null` disables the gesture recognizer for that callback. The drag indicator icon in the title bar should also be hidden in fullscreen mode to avoid confusion:
```dart
if (!isFullscreen) ...[
  const Icon(Icons.drag_indicator, size: 16, color: Tokens.textTertiary),
  const SizedBox(width: Tokens.spSm),
],
```
