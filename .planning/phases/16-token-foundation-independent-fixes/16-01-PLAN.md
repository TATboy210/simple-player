  <action>
    **UI-04: 添加 glowIntensity 参数 (per D-06, D-07, D-08, D-09)**

    1. 在 EdgeGlow 构造函数中添加 `final double? glowIntensity;` 参数，默认 null (D-06)

    2. 修改 `_buildGradientGlow()` 方法 (D-07)：
       - 移除 `const` 关键字（BoxShadow 列表不再是编译时常量）
       - 在方法开头计算 `final intensity = widget.glowIntensity ?? 1.0;`
       - 对每个 BoxShadow 的 color 使用 `.withValues(alpha: color.a * intensity)` 缩放 alpha

    3. 修改 `_buildPulseGlow()` 方法 (D-08)：
       - 在 AnimatedBuilder 内计算 `final intensity = widget.glowIntensity ?? 1.0;`
       - 将 pulse 振幅乘以 intensity：`0.03 + 0.05 * pulse * intensity`

    4. `_buildOmniGlow()` 方法不需要修改（使用 CustomPaint，不涉及 BoxShadow alpha）

    5. 在 `didUpdateWidget` 中添加 glowIntensity 变化检测 (D-09)：
       - 当 glowIntensity 从非 null 变为 null 或反之，触发 rebuild（已由 setState 自动处理）
       - 不需要额外的 AnimationController，因为 BoxShadow 的 alpha 变化是即时的

    **测试文件**

    创建 `test/widget/shared/edge_glow_test.dart`：
    - 测试默认 glowIntensity 为 null 时行为不变
    - 测试 glowIntensity=0.5 时 BoxShadow alpha 缩放
    - 测试 glowIntensity=0.0 时发光完全消失
    - 测试 glowIntensity=1.0 时与默认行为一致
  </action>
