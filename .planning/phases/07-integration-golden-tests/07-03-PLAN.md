# 窗口优化：BoxFit.contain + 自定义最大化

## 目标

1. 视频完整显示，非16:9内容显示黑边（BoxFit.contain）
2. 最大化按钮使用工作区（rcWork），任务栏不被覆盖
3. 全屏仍使用全监视器（rcMonitor），覆盖任务栏

## 背景

### 问题 1：视频裁剪

原实现使用 `BoxFit.cover`，当视频比例与窗口不同时会裁剪溢出部分。用户期望看到完整视频内容，黑边可接受。

### 问题 2：最大化覆盖任务栏

`windowManager.maximize()` 在无边框窗口上会覆盖任务栏。根因：`window_manager` 插件的 `adjustNCCALCSIZE` 在 `title_bar_style: "hidden"` 时将客户区扩展到整个监视器（`rcMonitor`），而非工作区（`rcWork`）。

## 实现

### 1. BoxFit.contain（video_surface.dart）

**改动：** `BoxFit.cover` → `BoxFit.contain`

```dart
// lib/ui/player/video_surface.dart:38
child: FittedBox(
  fit: BoxFit.contain,  // 原为 BoxFit.cover
  child: SizedBox(
    width: safeRatio >= 1 ? safeRatio * 1000 : 1000,
    height: safeRatio >= 1 ? 1000 : 1000 / safeRatio,
    child: Texture(textureId: id),
  ),
),
```

**效果：**
- 16:9 视频在 16:9 窗口：无黑边
- 4:3 视频在 16:9 窗口：左右黑边（pillarbox）
- 16:9 视频在 4:3 窗口：上下黑边（letterbox）
- 背景色：`Tokens.bgBase`（`0xFF0A0A0F`）近黑色

### 2. 自定义 maximize()（window_service.dart）

**改动：** 重写 `maximize()` 和 `restore()`，使用 Win32 FFI 直接操作

```dart
// lib/kernel/bridge/window_service.dart:354-390
Future<void> maximize() async {
  if (isMaximized.value) return;
  final hwnd = await windowManager.getId();

  // 保存当前窗口位置（用于 restore）
  final frame = calloc<_Rect>();
  _getWindowRect(hwnd, frame);
  final saved = calloc<_Rect>()
    ..ref.left = frame.ref.left
    ..ref.top = frame.ref.top
    ..ref.right = frame.ref.right
    ..ref.bottom = frame.ref.bottom;
  _savedMaximizeFrame = saved;
  calloc.free(frame);

  // 获取工作区（排除任务栏）
  final hMonitor = _monitorFromWindow(hwnd, _monitorDefaultToNearest);
  final mi = calloc<_MonitorInfo>();
  mi.ref.cbSize = sizeOf<_MonitorInfo>();
  _getMonitorInfo(hMonitor, mi);

  // 定位到工作区
  await _setTransitionsDisabled(true);
  _setWindowPos(
    hwnd,
    _hwndTop,
    mi.ref.rcWork.left,
    mi.ref.rcWork.top,
    mi.ref.rcWork.right - mi.ref.rcWork.left,
    mi.ref.rcWork.bottom - mi.ref.rcWork.top,
    _swpNoOwnerZOrder | _swpFrameChanged,
  );
  await _setTransitionsDisabled(false);

  calloc.free(mi);
  if (!isMaximized.value) isMaximized.value = true;
}
```

**关键点：**
- 使用 `GetMonitorInfoW` 获取 `rcWork`（工作区，排除任务栏）
- 使用 `SetWindowPos` 定位窗口到工作区
- `_savedMaximizeFrame` 保存最大化前位置，用于 `restore()`
- `DWMWA_TRANSITIONS_FORCEDISABLED` 包裹操作，消除白边闪现

### 3. restore() 实现

```dart
// lib/kernel/bridge/window_service.dart:393-412
Future<void> restore() async {
  if (!isMaximized.value || _savedMaximizeFrame == null) return;
  final hwnd = await windowManager.getId();

  await _setTransitionsDisabled(true);
  _setWindowPos(
    hwnd,
    0,
    _savedMaximizeFrame!.ref.left,
    _savedMaximizeFrame!.ref.top,
    _savedMaximizeFrame!.ref.right - _savedMaximizeFrame!.ref.left,
    _savedMaximizeFrame!.ref.bottom - _savedMaximizeFrame!.ref.top,
    _swpNoOwnerZOrder | _swpFrameChanged,
  );
  await _setTransitionsDisabled(false);

  calloc.free(_savedMaximizeFrame!);
  _savedMaximizeFrame = null;
  if (isMaximized.value) isMaximized.value = false;
}
```

## 设计决策

| 决策 | 理由 |
|------|------|
| `BoxFit.contain` 替代 `BoxFit.cover` | 用户要求完整显示视频，黑边可接受 |
| 自定义 FFI `maximize()` 替代 `windowManager.maximize()` | 插件的 `adjustNCCALCSIZE` 在无边框窗口覆盖任务栏 |
| 使用 `rcWork` 而非 `rcMonitor` | 标准 Windows 最大化行为：工作区不含任务栏 |
| `DWMWA_TRANSITIONS_FORCEDISABLED` 包裹操作 | 消除无边框窗口的白边闪现和卡顿动画 |
| `_savedMaximizeFrame` 模式 | 与全屏的 `_savedFrame` 模式一致，保存/恢复窗口位置 |
