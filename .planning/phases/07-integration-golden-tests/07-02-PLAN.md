  <action>
Create the golden test directory and a custom golden file comparator that handles cross-machine rendering differences.

**Create `test/golden/golden_comparator.dart`:**

Implement `TolerantGoldenComparator` that wraps Flutter's default comparator with pixel-level tolerance:

- Class `TolerantGoldenComparator` implements `GoldenFileComparator`.
- Constructor takes `this.tolerance` (default `0.05` = 5% per-channel difference).
- `compare()` method: loads the golden file (if exists) and the test image, compares pixel-by-pixel. If the golden file does not exist, creates it (first-run behavior). Returns `Future<void>` — throws on mismatch.
- Pixel comparison: For each pixel, compute per-channel absolute difference (R, G, B, A). If any channel differs by more than `tolerance * 255`, count it as a mismatched pixel. If mismatched pixels exceed `maxMismatchRate` (default `0.01` = 1% of total pixels), fail the comparison.
- `update()` method: delegates to the default comparator for `--update-goldens`.
- Provide a `setUp` function `enableTolerantGoldens()` that sets `goldenComparator = TolerantGoldenComparator()`.

Additionally, for BackdropFilter-based widgets (GlassContainer, ControlBar), note that the blur effect cannot render in the Flutter test environment (no real compositing). Tests should use `blurEnabled: false` to test layout/styling without blur, OR test with blur enabled and mark those goldens as "layout-only" (the blur area will be transparent/black).

Provide a helper `wrapForGolden(Widget child)` that wraps in `MaterialApp` + `Scaffold` with a fixed 800x600 `SizedBox` and a solid background color (`Color(0xFF1A1A2E)`) so golden images have a consistent dark background matching the player theme.
