  <action>
Create `test/kernel/engine/race_condition_test.dart` with fakeAsync-based race condition tests.

These tests validate the EngineStateMachine's generation tracking and state transition correctness under rapid-fire scenarios. They use the state machine directly (not the full FvpEngine) to isolate state transition logic.

**Test structure:**

```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:simple_player_flutter/kernel/engine/engine_state_machine.dart';
import 'package:simple_player_flutter/kernel/engine/media_state.dart';
import 'package:simple_player_flutter/kernel/engine/transition_result.dart';
import 'package:simple_player_flutter/kernel/engine/lifecycle_phase.dart';
```

**Test groups:**

1. `group('Race condition — generation tracking')`:
   - `test('rapid open-open: second open rejects first open transitions')`:
     - Create machine, call nextGeneration() twice (gen1=1, gen2=2)
     - Simulate: transitionTo(opening, 'open1', generation: gen1) → ok
     - Simulate: transitionTo(opening, 'open2', generation: gen2) → ok (overrides)
     - Simulate: transitionTo(idle, 'open1-complete', generation: gen1) → staleGeneration
     - Assert: state is opening (from open2), not idle
   - `test('stale generation returns TransitionResult.staleGeneration')`:
     - Call nextGeneration() 3 times, use gen=1
     - Assert transitionTo returns TransitionResult.staleGeneration

2. `group('Race condition — open-seek-open interleaved')`:
   - `test('seek between two opens: final state matches last open')`:
     - gen1 = nextGeneration(), transitionTo(opening, gen: gen1)
     - Simulate seek (state still opening, seek is no-op in opening state)
     - gen2 = nextGeneration(), transitionTo(opening, gen: gen2)
     - transitionTo(idle, gen: gen2) → ok
     - transitionTo(idle, gen: gen1) → staleGeneration
     - Assert: state is idle (from gen2's completion)

3. `group('Race condition — open-dispose lifecycle')`:
   - `test('dispose during open: lifecyclePhase transitions correctly')`:
     - gen = nextGeneration(), transitionTo(opening, gen: gen)
     - Set lifecyclePhase to disposing
     - Assert lifecyclePhase.value == LifecyclePhase.disposing
     - transitionTo(idle, gen: gen) → ok (state machine doesn't block on lifecycle)
     - Dispose machine, assert lifecyclePhase.value == LifecyclePhase.disposed

4. `group('Race condition — open-play-pause-open rapid fire')`:
   - `test('rapid sequence: final state matches last valid transition')`:
     - gen1 = nextGeneration(), transitionTo(opening, gen: gen1)
     - transitionTo(playing, gen: gen1) → ok
     - gen2 = nextGeneration(), transitionTo(opening, gen: gen2)
     - transitionTo(playing, gen: gen1) → staleGeneration (gen1 expired)
     - transitionTo(playing, gen: gen2) → ok
     - Assert: state is playing (from gen2)

5. `group('Race condition — recover during rapid operations')`:
   - `test('recover after error from stale generation')`:
     - gen1 = nextGeneration(), transitionTo(opening, gen: gen1)
     - transitionTo(error, gen: gen1) → ok
     - gen2 = nextGeneration() (user initiated new open)
     - recover() → transitions error->idle
     - Assert: state is idle, ready for gen2's open

All tests use the real EngineStateMachine (no mocks needed). Tests verify both TransitionResult return values and final state values.
