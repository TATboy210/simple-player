**Changes to EngineStateMachine:**

1. **Imports**: Add `lifecycle_phase.dart`, `transition_result.dart`, `kernel_logger.dart`

2. **LifecyclePhase notifier** (D6):
   - Add field: `final ValueNotifier<LifecyclePhase> lifecyclePhase = ValueNotifier(LifecyclePhase.alive);`
   - This is orthogonal to `state` (MediaState) — both coexist independently

3. **OpenGenerationTracker** (D5, blocking constraint #3):
   - Add field: `int _openGeneration = 0;`
   - Add method: `int nextGeneration() => ++_openGeneration;`
   - Add getter: `int get currentGeneration => _openGeneration;`

4. **TransitionResult return type** (D4, blocking constraint #4):
   - Change `transitionTo` signature from `bool transitionTo(MediaState next, String caller)` to `TransitionResult transitionTo(MediaState next, String caller, {int? generation})`
   - If `generation != null && generation != _openGeneration`: log warning via `KernelLogger.I.warn(...)`, return `TransitionResult.staleGeneration`
   - If `!_canTransitionTo(current, next)`: log warning via `KernelLogger.I.warn(...)` (NOT assert-only), return `TransitionResult.illegal`
   - On success: set `state.value = next`, return `TransitionResult.ok`
   - Remove the old `assert(() { debugPrint(...); return true; }())` pattern entirely

5. **recover() method** (D7):
   - `void recover()` — transitions error -> idle, clears lastError notifier if provided
   - Only works when `state.value == MediaState.error`, otherwise no-op
   - Signature: `void recover({ValueNotifier<PlayerError?>? lastError})`
   - Implementation: `if (state.value == MediaState.error) { state.value = MediaState.idle; lastError?.value = null; }`

6. **Double-dispose safety** (D8):
   - Add field: `bool _disposed = false;`
   - In `dispose()`: check `_disposed`, if true return early. Set `_disposed = true`, then dispose all notifiers including `lifecyclePhase`.

7. **Update togglePlayPause**: No changes needed — it operates on state.value which is unchanged.

8. **Update _canTransitionTo**: No changes needed — the switch expression is already exhaustive.

**Test updates** (update existing test file):

- All existing tests that check `transitionTo` return `true`/`false` must be updated to check `TransitionResult.ok`/`TransitionResult.illegal`
- Add new test group: `OpenGenerationTracker` — test nextGeneration(), currentGeneration, stale generation rejection
- Add new test group: `LifecyclePhase` — test initial value is alive, transitions to disposing/disposed
- Add new test group: `recover()` — test error->idle transition, no-op when not in error state, lastError cleared
- Add new test group: `double-dispose` — test second dispose() is safe no-op
- Add new test group: `TransitionResult` — test all three values returned correctly
- All existing togglePlayPause and flag tests remain unchanged

**Important**: The import of `kernel_logger.dart` uses `KernelLogger.I` static accessor (Phase 17 D1). In test environment, KernelLogger.I returns a NullKernelLogger by default — no mock needed.
