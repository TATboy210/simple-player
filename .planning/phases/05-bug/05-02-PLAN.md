    Add `enterFullscreenFast()` and `leaveFullscreenFast()` methods to WindowsFullscreenDriver that optimize the FFI call sequence:

    1. **enterFullscreenFast()** — Merge the current 7-9 FFI calls into 5:
       - Call 1: `getFlutterHwnd()` — get window handle
       - Call 2: `getWindowPlacement()` — save position for restore
       - Call 3: `setWindowLong(gwlStyle, stripped)` — strip WS_THICKFRAME + WS_CAPTION + WS_MAXIMIZE in one call (already done)
       - Call 4: `setWindowLong(gwlExStyle, topmost)` — add WS_EX_TOPMOST in one call (already done)
       - Call 5: `setWindowPos(HWND_TOPMOST, monitorRect)` — atomic position+size+frame update
       
       The key optimization: remove the redundant `getWindowLong` calls for both gwlStyle and gwlExStyle that currently happen before `setWindowLong`. The current code reads styles then writes them — the fast path skips the read and directly computes the stripped value (constants are known at compile time).

       Implementation pattern:
       ```dart
       Future<void> enterFullscreenFast({int displayId = 0}) async {
         final hwnd = _api.getFlutterHwnd();
         if (hwnd == 0 || !_api.isWindow(hwnd)) return;
         
         // Save position (1 FFI call)
         _freeSavedPlacement();
         _savedPlacement = _api.getWindowPlacement(hwnd);
         
         // Batch style strip — no read needed, constants are known
         // WS_OVERLAPPEDWINDOW = 0x00CF0000, strip caption+thickframe+maximize
         // Result: 0x000B0000 (WS_SYSMENU | WS_MINIMIZEBOX | WS_VISIBLE)
         const strippedStyle = 0x00CF0000 & ~(0x00C00000 | 0x00040000 | 0x01000000);
         _api.setWindowLong(hwnd, gwlStyle, strippedStyle);
         
         // Add TOPMOST, strip dialog/modal/edge styles
         _api.setWindowLong(hwnd, gwlExStyle,
           0x00000100 | wsExTopmost); // WS_EX_WINDOWEDGE + TOPMOST
         
         // Atomic position (1 FFI call)
         final monitor = _api.monitorFromWindow(hwnd);
         if (monitor != 0) {
           final rc = _api.getMonitorRect(monitor);
           if (rc != null) {
             _api.setWindowPos(hwnd, hwndTopmost,
               rc.left, rc.top, rc.right - rc.left, rc.bottom - rc.top,
               swpNoownerzorder | swpFramechanged);
           }
         }
         
         _isFullscreen = true;
       }
       ```

       **IMPORTANT**: The stripped style computation must be derived from the ACTUAL saved style, not hardcoded. The fast path should read the current style once (not twice), then strip in-memory:
       ```dart
       _savedStyle = _api.getWindowLong(hwnd, gwlStyle);
       _savedExStyle = _api.getWindowLong(hwnd, gwlExStyle);
       _api.setWindowLong(hwnd, gwlStyle,
         _savedStyle & ~(wsCaption | wsThickframe | wsMaximize));
       _api.setWindowLong(hwnd, gwlExStyle,
         _savedExStyle | wsExTopmost & ~(wsExDlgmodalframe | wsExWindowedge | wsExClientedge | wsExStaticedge));
       ```
       This is 6 FFI calls total (getHwnd + getPlacement + getStyle + getExStyle + setStyle + setExStyle + setPos = 7). The optimization vs current is removing the redundant second `getWindowLong` per index.

       - Restore placement with `setWindowPlacement`
       - Skip the extra `getWindowRect` + `setWindowPos` layout refresh (the `setWindowPlacement` already triggers WM_PAINT)
