# 05-05: 全屏切换闪烁消除

## 问题诊断

通过 Flutter SDK 源码级分析，识别出 5 个根因：

| # | 根因 | SDK 机制 | 严重度 |
|---|------|----------|--------|
| 1 | Widget 类型变化触发 Element 销毁重建 | `canUpdate` 要求 `runtimeType` 相同 | 🔴 高 |
| 2 | `_updateOnUIThread` phase 检查延迟 1 帧 | `addPostFrameCallback` 在 paint 后执行 | 🔴 高 |
| 3 | `isResizing` 触发控制栏不必要淡出 | `ValueNotifier.notifyListeners()` 同步通知 | 🟡 中 |
| 4 | 两条事件链时序不同步 | Flutter resize 1帧 vs window_manager 100ms+ | 🟡 中 |
| 5 | 双层 AnimatedBuilder 冗余重建 | 同一 notifier 触发两次 `markNeedsBuild` | 🟠 低 |

## 帧序列分析（当前）

```
F0: 正常窗口 (mode=windowed, DragToResizeArea)
F1: FFI SetWindowPos 执行，边框消失
F2: 窗口已全屏尺寸，但 mode=windowed 仍为 windowed
    → DragToResizeArea 以 windowed 布局渲染到全屏窗口 = 布局错位！
    → onWindowResize → isResizing=true → 控制栏开始淡出！
F3: mode 更新为 fullscreen
    → AnimatedBuilder rebuild
    → canUpdate(DragToResizeArea, MouseRegion) = false
    → 整棵子树 deactivate + inflate
    → Texture RenderObject 销毁重建 → textureId 短暂 null → 1帧黑屏！
F4+: 稳定，但控制栏仍在淡出动画中 (800ms)
```

## Must Have

1. 全屏切换无黑帧（Texture 子树不被销毁重建）
2. 全屏切换无布局错位帧（mode 在 FFI 执行前或同步更新）
3. 全屏切换时控制栏不闪烁（跳过 isResizing 淡出）
4. 进入全屏 FFI 调用从 14-16 次降至 5-7 次

## Tasks

### T1: 统一 Widget 类型 — 消除 Element 销毁重建

**文件:** `lib/ui/player/player_screen.dart`

**当前代码 (行 234-247):**
```dart
AnimatedBuilder(
  animation: widget.windowService.mode,
  builder: (context, child) {
    final m = widget.windowService.mode.value;
    if (m.isFullscreen || m.isMaximized) {
      return MouseRegion(cursor: SystemMouseCursors.basic, child: child);
    }
    return DragToResizeArea(child: child!);
  },
  child: keyboardHandler,
)
```

**修复方案:**
- `DragToResizeArea` 增加 `enabled` 属性（默认 true）
- `enabled = false` 时内部用 `IgnorePointer` 包裹 child，不拦截拖拽
- `AnimatedBuilder` 始终返回 `DragToResizeArea`，通过 `enabled` 控制行为
- `canUpdate` 返回 true → Element 复用 → Texture 子树稳定

**测试:** `test/widget/player/player_screen_test.dart`
- 验证 mode 切换时 DragToResizeArea Element 不被销毁
- 验证全屏时 IgnorePointer 生效
- 验证窗口模式时拖拽功能正常

### T2: 同步更新 mode — 消除 1 帧延迟

**文件:** `lib/kernel/bridge/window_service.dart`

**当前代码 (行 ~146):**
```dart
// mode 通过 _onFullscreenEvent → _updateOnUIThread 更新
// 可能延迟 1 帧
```

**修复方案:**
- 在 `setMode(WindowMode.fullscreen)` 中直接设置 `_state.mode.value = fullscreen`
- 在 `setMode(WindowMode.windowed)` 中直接设置 `_state.mode.value = windowed`
- 不再依赖 `_onFullscreenEvent` 回调链更新 mode
- `Entered`/`Left` 事件到达时 mode 已是目标值，不触发额外 rebuild

**风险:** 需确保其他监听 `FullscreenEvent` 的组件（如命令队列）不受影响。`FullscreenAdapter` 内部的 `FullscreenSnapshot` 仍通过事件驱动，只是 `WindowService.mode` 改为同步更新。

**测试:** `test/kernel/bridge/window_service_test.dart`
- 验证 setMode(fullscreen) 后 mode.value 立即为 fullscreen
- 验证 setMode(windowed) 后 mode.value 立即为 windowed
- 验证 Entered 事件不会触发额外 mode 更新

### T3: 全屏切换跳过 isResizing 控制栏淡出

**文件:** `lib/ui/player/controls_overlay.dart`

**当前代码:**
```dart
void _onResizeChanged() {
  if (resizing) {
    _animController.reverse(); // 150ms 淡出
  } else {
    _animController.forward(); // 150ms 淡入
  }
}
```

**修复方案:**
- `_onResizeChanged` 中检测 `widget.isFullscreen` 是否正在变化
- 全屏切换期间跳过 `reverse()`，保持控制栏当前状态
- 用 `didUpdateWidget` 检测 `isFullscreen` 变化，设置 `_isFullscreenTransition` 标记
- 全屏切换完成后清除标记，恢复正常 resize 行为

**测试:** `test/widget/player/controls_overlay_test.dart`
- 验证全屏切换时动画控制器不执行 reverse
- 验证用户拖拽调整窗口大小时淡出仍正常工作
- 验证全屏切换完成后控制栏响应正常

### T4: 合并快照 FFI 调用 — 从 14-16 降至 5-7

**文件:** `lib/kernel/bridge/platform/windows_fullscreen_driver.dart`

**当前问题:**
- `_captureRestoreSnapshot` 调用 3 个独立方法，每个绕过缓存调 `getFlutterHwnd()`
- `isMinimized()` 检查也绕过缓存
- 合计 6-8 次冗余 FFI

**修复方案:**
- `WindowsFullscreenDriver` 新增 `captureSnapshot()` 批量方法
  - 使用 `_getHwnd()` 缓存
  - `isZoomed(hwnd)` + `getWindowPlacement(hwnd)` = 2 FFI
  - 返回 `({bool isMaximized, Offset position, Size size})`
- `_captureRestoreSnapshot` 调用此方法替代 3 个独立调用
- `isMinimized` 检查合并到 `enterFullscreenFast` 内部
- `enterFullscreenFast` 中 `getWindowPlacement` 复用快照结果

**预期:** 进入全屏 FFI 从 14-16 次降至 5-7 次

**测试:** `test/platform/windows_fullscreen_driver_test.dart`
- 验证 captureSnapshot 返回正确值
- 验证 FFI 调用次数（getWindowPlacement 只调 1 次）
- 验证 enterFullscreenFast 总 FFI ≤ 7

### T5: 合并双层 AnimatedBuilder

**文件:** `lib/ui/player/player_screen.dart`

**当前代码 (行 274-305):**
```dart
AnimatedBuilder(
  animation: widget.windowService.mode,
  builder: (context, _) {
    final isFullscreen = widget.windowService.mode.value.isFullscreen;
    return ControlsOverlay(..., isFullscreen: isFullscreen, ...);
  },
)
```

**修复方案:**
- 移除内层 `AnimatedBuilder`
- `isFullscreen` 从外层 AnimatedBuilder 读取，通过参数传入 `_buildVideoContent`
- `_buildVideoContent` 增加 `bool isFullscreen` 参数
- `ControlsOverlay` 直接使用传入的 `isFullscreen`
