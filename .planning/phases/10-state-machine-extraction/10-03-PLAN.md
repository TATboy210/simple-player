## Root Cause Analysis

### GAP-2 & GAP-3: ISP 接口未实现

**根本原因:** VideoEffectControl 和 SubtitleConfig 接口包含了 ValueNotifier getter:

```dart
// VideoEffectControl — line 23
ValueNotifier<double> get aspectRatio;  // ← 由 FvpEngine 拥有，非 controller

// SubtitleConfig — lines 29, 32
ValueNotifier<String> get subtitleText;  // ← 由 FvpEngine 拥有
int get subtitleDelay;                    // ← 委托给 SubtitleConfigurator
```

VideoEffectController 和 SubtitleConfigurator 不拥有这些 ValueNotifier，
因此无法 implements 对应接口。

**解决方案:** 从 control 接口中移除 ValueNotifier getter。这些 getter 属于
EngineStateView（只读状态层），不应在 control 接口中重复定义。

### GAP-1: FvpEngine 609 行 (目标 <350)

**根本原因:** MediaEngine extends 6 个接口 (EngineStateView + PlaybackControl +
TrackControl + SubtitleConfig + VideoEffectControl + RendererControl + VolumeControl)。
FvpEngine implements MediaEngine，必须实现所有方法。

82 个调用点分布在 15 个文件中，迁移调用方到 interface getter 是 Phase 13 范围。

**决策:** GAP-1 在 Phase 10 无法完全解决 — 需要 Phase 13 的调用方迁移。
记录此决策，Phase 10 完成 GAP-2 和 GAP-3。

</analysis>
