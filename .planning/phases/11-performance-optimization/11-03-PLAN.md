<objective>
Add refresh-rate-aware D3D11 sync mode — detect display refresh rate via Win32 EnumDisplaySettings FFI and set d3d11.sync.cpu accordingly (async on 120Hz+, sync on 60Hz).

Purpose: High-refresh-rate displays (120Hz, 144Hz, 240Hz) benefit from async D3D11 mode for lower latency. The current hardcoded sync mode (d3d11.sync.cpu=1) is safe but suboptimal on high-refresh displays. Async mode reduces CPU-GPU synchronization overhead.

Output: New display_config.dart, modified win32_bindings.dart with EnumDisplaySettings FFI, modified fvp_engine.dart using DisplayConfig policy.
</objective>
