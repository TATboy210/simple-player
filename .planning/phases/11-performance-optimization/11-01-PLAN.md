<objective>
Replace ThumbnailService's O(n) LRU cache (Map + List) with O(1) LinkedHashMap implementation.

Purpose: The current _touch() uses List.remove() which is O(n), and _evictIfNeeded() uses List.removeAt(0) which is also O(n) due to shifting. With _maxCacheSize=200, this is measurable on every playlist item hover. LinkedHashMap gives O(1) remove + reinsert.

Output: Modified thumbnail_service.dart with LinkedHashMap, expanded tests verifying LRU ordering.
</objective>
