# 11-01: 引擎解耦 + 防御增强

## ENG-04: open() generation 计数器

**当前状态:** FvpEngine 用 `bool _isOpening` 防止并发 open，PlaybackNavigator 用 `int _openGeneration` 防止导航级 stale result。引擎层缺少 generation 守卫。

**方案:** 用 `_openGeneration` 替代 `_isOpening`，每次 open() 递增，async 返回后检查 generation。

### Task 1: FvpEngine.open() 改造

**File:** `lib/kernel/engine/fvp_engine.dart`

- `_isOpening = false` → `int _openGeneration = 0`
- open() 开头: `final gen = ++_openGeneration`
- await 返回后: `if (_disposed || gen != _openGeneration) return`
- finally 块: `if (gen == _openGeneration) isBuffering.value = false`
- 删除 codec 重试中的 `_isOpening = false`

### Task 2: 更新 FakeEngine

**File:** `test/helpers/fake_engine.dart`

- 添加 `_openGeneration` 计数器
- open() 中使用 generation 检查

### Task 3: 编写 generation 测试

**File:** `test/kernel/engine/fvp_engine_open_test.dart` (NEW)

- 测试: 快速连续 open()，旧结果被丢弃
- 测试: open 后 dispose 不更新状态

## SVC-03: StateMonitor 职责拆分

**当前状态:** StateMonitor (163行) 混合三类职责: 设置恢复、断点保存、自动连播。

### Task 4: 创建 PlaybackStateManager

**File:** `lib/kernel/services/playback_state_manager.dart` (NEW)

职责:
- init(): 从 SettingsStore 加载音量/静音 → engine.setVolume/setMute
- _onStateChanged(): paused → 保存断点位置
- dispose(): 保存音量/静音/播放模式 + 当前位置

### Task 5: 创建 AutoAdvancePolicy

**File:** `lib/kernel/services/auto_advance_policy.dart` (NEW)

职责:
- init(): 注册 engine.state 监听
- _onStateChanged(): completed → loopSingle 重播 or 自动下一首
- dispose(): 注销监听

### Task 6: 重构 PlaybackController

**File:** `lib/kernel/services/playback_controller.dart`

- `StateMonitor monitor` → `PlaybackStateManager stateManager` + `AutoAdvancePolicy autoAdvance`
- 构造函数中创建两个新实例
- init() 调用 stateManager.init() + autoAdvance.init()
- dispose() 调用两者 dispose()

### Task 7: 删除旧 StateMonitor + 更新测试

- 删除 `lib/kernel/services/state_monitor.dart`
- 重写 `test/kernel/services/state_monitor_test.dart` → 拆分为两个测试文件
