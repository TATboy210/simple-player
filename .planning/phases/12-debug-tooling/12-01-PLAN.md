       - Create shared `filter = ProductionFilter(Level.warning)` (explicit threshold per D-13)
       - Create shared `output = MultiOutput([ConsoleOutput(), _RotatingFileOutput(dir, file, maxBytes: 2 * 1024 * 1024)])`

       - Reassign module loggers: `logEngine = Logger(filter: filter, printer: PrefixPrinter('engine', printer), output: output)` etc.
       - This ensures module loggers get release config even though they were declared with debug defaults (per Pitfall 4)
