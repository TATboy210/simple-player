<objective>
**用户故事：作为播放器用户，我希望任何错误发生后都能在界面左上角看到一张常驻、不阻碍操作的非模态错误卡片，以便在不打断播放的情况下立即获知出了什么问题。**

建立 Phase 3 的 production tracer：把一份真实接纳的 ErrorReport 贯穿 `ErrorReporterImpl.presentation` → `ErrorCardHost`（CARD-05 相位守卫适配器）→ `ErrorCard` 折叠视图 → app root Stack 挂载（D-10 修订层）。随后锁死 build 期安全（CARD-05）与预挂载补呈现（D-12）。

Purpose: 先证明「报告→呈现状态→宿主→可见卡片」全链路可在真实调度环境下无次生错误地运行，再在后续计划富化展开详情、复制、徽标轮览与 MIG-01 迁移。
Output: ErrorCardHost/ErrorCard 骨架、app root 挂载、全部 Wave 0 l10n key、端到端测试。
</objective>

| ErrorReport → 卡片 UI | 报告 message/stack 由捕获侧脱敏，但渲染层是最终防线（不得引入未脱敏字段）。 |
