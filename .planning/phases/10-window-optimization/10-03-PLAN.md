  <action>Modify lib/main.dart to restore saved geometry before showing the window. Changes:

1. Add import: `import 'kernel/bridge/window_bootstrap.dart';`

2. Inside the `waitUntilReadyToShow` callback (currently lines 27-31), restructure to:
   - Keep `await WindowService.removeBorderImmediate();` as first call
   - Add `final settings = await SettingsStore.load();` to read saved geometry
   - Add `await WindowBootstrap.clearFullscreenIfSaved(settings);` per D-02
   - Add `await WindowBootstrap.restoreOrCenter(settings);` to apply saved geometry
   - Keep `await windowManager.show();` and `await windowManager.focus();`
   - After show+focus, add maximize restore: `if (settings.isMaximized) { /* maximize handled below */ }`

3. For maximize restore on startup: Since WindowService is not yet created at this point in main.dart (it's created later in App), and we need the FFI-based maximize, we have two options:
   - Option A: Use `windowManager.maximize()` (window_manager package) — simpler but may not use rcWork
   - Option B: Defer maximize to after WindowService is created in App
   - Choose Option A for simplicity: `if (settings.isMaximized) { await windowManager.maximize(); }` — this uses window_manager's maximize which is acceptable at startup since the custom FFI maximize is mainly for runtime toggle

4. Remove `center: true` from WindowOptions since WindowBootstrap.restoreOrCenter handles centering. Change WindowOptions to only include non-geometry fields:
   ```
   const windowOptions = WindowOptions(
     backgroundColor: Colors.transparent,
     titleBarStyle: TitleBarStyle.hidden,
     windowButtonVisibility: false,
     minimumSize: Size(854, 480),
   );
   ```
   Note: Remove `size: Size(960, 540)` and `center: true` — these are now handled by WindowBootstrap.

5. The `SettingsStore.load()` call inside waitUntilReadyToShow is separate from the later `SettingsStore.prewarm(prefs)` at line 45. The prewarm caches the prefs instance; load() reads from it. Since prewarm happens AFTER the callback (it's async, fired by waitUntilReadyToShow which triggers when window is ready), we need to ensure prefs are available. Solution: Move `final prefs = await SharedPreferences.getInstance(); SettingsStore.prewarm(prefs);` BEFORE the waitUntilReadyToShow call, so the cached instance is available when load() is called inside the callback.</action>
