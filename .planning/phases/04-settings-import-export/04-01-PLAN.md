**Step 3: Add ImportResult sealed class and importSettings method (per D-02, D-07, D-08)**

Add a sealed class `ImportResult` at the top of settings_store.dart (following the pattern from `lib/kernel/engine/open_result.dart`):

```dart
/// Result of importing settings from JSON — sealed for exhaustive pattern matching.
sealed class ImportResult {
  const ImportResult();
}

/// Import succeeded — carries parsed settings and supplementary values.
final class ImportSuccess extends ImportResult {
  final AppSettings settings;
  final String locale;
  final int themeIndex;
  final Map<String, String> shortcuts;
  const ImportSuccess({required this.settings, required this.locale, required this.themeIndex, required this.shortcuts});
}

/// Import failed — carries a human-readable error description.
final class ImportFailure extends ImportResult {
  final String error;
  const ImportFailure(this.error);
}
```

Add static async method `importSettings(String jsonString) → Future<ImportResult>` that:
1. Tries `jsonDecode(jsonString)` — catches `FormatException` and returns `ImportFailure('Invalid JSON: ...')`
2. Extracts `data['settings']` — if null or not a Map, returns `ImportFailure('Missing settings data')`
3. Creates `AppSettings` from the settings map with defaults for missing fields:
   - Use `map['volume'] as double?` pattern with null-coalescing to AppSettings constructor defaults
   - Apply SettingsValidator to each field: `SettingsValidator.volume(raw)`, `SettingsValidator.playMode(raw)`, `SettingsValidator.sanitizeDimension(...)`, etc.
   - For locale: `map['locale'] as String? ?? SettingsValidator.defaultLocale`
   - For themeIndex: `SettingsValidator.themeIndex(map['themeIndex'] as int? ?? 0)`
   - For shortcuts: parse as `Map<String, String>` with empty map default
4. Returns `ImportSuccess(settings: validatedSettings, locale: validatedLocale, themeIndex: validatedThemeIndex, shortcuts: validatedShortcuts)`

**Step 4: Add applyImportedSettings method (per D-14)**

Add static async method `applyImportedSettings(ImportSuccess result) → Future<void>` that:
1. Calls `await saveAll(result.settings)` to persist AppSettings
2. Calls `await saveLocale(result.locale)` to persist locale
3. Calls `await saveThemeIndex(result.themeIndex)` to persist themeIndex
4. Calls `await saveShortcuts(result.shortcuts)` to persist shortcuts
5. Wraps in try-catch, logs via `log.e` on failure

This method is called by the UI after import confirmation. It persists everything so that on next app load, all settings are from the imported file. Note: parameter type is `ImportSuccess` (not `ImportResult`) — callers must pattern-match first.
