**Step 5: Handle locale/theme after import (per D-14)**

After import, the imported locale and theme need to take effect immediately:
- `LocaleService.I.setLocale(result.locale)` — updates locale and persists (no `!` needed — `ImportSuccess` fields are non-nullable)
- `ThemeService.I.setTheme(result.themeIndex)` — updates theme and persists
- Update `_pendingLocale` and `_pendingThemeIndex` so the panel reflects the new values
- Do NOT call `_commitChanges()` — that would apply locale/theme twice (once here, once on OK). Since import is "immediate apply" per D-14, we set them directly.

Actually, per D-14: "导入成功后立即应用所有设置（不等 OK/Cancel）". This means ALL settings are applied immediately, not just locale/theme. The `applyImportedSettings` persists everything. For locale/theme, we also need to call the services so the UI updates in real-time. For other settings (volume, video effects, etc.), they are persisted and will take effect on next read.

The key insight: after import, the panel should reflect the imported values. So:
- Update `_pendingLocale = result.locale` 
- Update `_pendingThemeIndex = result.themeIndex`
- Call `LocaleService.I.setLocale(result.locale)` — immediate UI update
- Call `ThemeService.I.setTheme(result.themeIndex)` — immediate UI update
- For other settings: they are persisted via `saveAll`, and the tabs read them on next build. Since we're in the same panel, the tabs won't automatically refresh. We could force a rebuild by incrementing a counter, or accept that tab contents refresh on next tab switch.

Given the complexity, the simplest approach for D-14 is:
1. Persist all imported settings via `applyImportedSettings`
2. Apply locale/theme immediately via services
3. Update pending values in setState
4. The panel stays open per D-15 — tab contents will reflect new values on next tab switch or panel rebuild
