<objective>
Fix fullscreen toggle so all 4 entry points (F key, button, double-click, ESC) work correctly. The root cause: `_enterFullscreenInternal()` and `_exitFullscreenInternal()` perform visual fullscreen via setSize+setPosition but never update `mode.value` or persist state. This means the toggle branch always enters fullscreen (never exits), ESC never fires (checks isFullscreen which is always false), and the button icon never changes.

Purpose: Restore fullscreen as a reliable, persistent feature
Output: window_service.dart with optimistic mode.value + persistence, controls_overlay.dart double-click verified
</objective>
