**Root cause analysis:**

1. **PlayerServices.create error**: `player_view_model.dart:62` 调用 `PlayerServices.create()` 但 `player_services.dart` 只有构造函数 + `init()` 方法，没有静态工厂方法。

2. **External subtitle test failures**: `state_monitor.dart:126` 在 dispose 时调用 `PlaylistStore.dispose()`，该方法内部使用 `path_provider` 插件。测试环境没有 mock path_provider，导致 `MissingPluginException`。错误链：
   ```
   test tearDown → controller.dispose() → state_monitor.dispose()
   → PlaylistStore.dispose() → getApplicationSupportDirectory()
   → MissingPluginException
   ```

3. **overridden_fields (24)**: `EngineState` 是一个 `mixin`，定义了 `ValueNotifier` 字段（如 `textureId`, `state`, `position` 等）。`FvpEngine` 和 `FakeEngine` 都继承这个 mixin 并重新声明这些字段。这是有意的设计——每个引擎实例需要自己的 ValueNotifier 实例。正确做法是添加 `@override` 注解。

4. **unnecessary_import (12)**: `engine_state.dart` 通过 `export` 重新导出了所有类型（`media_error_type.dart`, `media_state.dart`, `audio_track_info.dart` 等）。`fvp_engine.dart` 和 `mock_engine.dart` 同时 import 了 `engine_state.dart` 和这些子模块，导致重复 import。

5. **deprecated_member_use (18)**: Flutter 3.27+ 弃用了 Color 的整数访问器（`.value`, `.alpha`, `.red`, `.green`, `.blue`），新的 double-based API（`.a`, `.r`, `.g`, `.b`, `.toARGB32()`）更安全。

### Task 2: Fix external subtitle test failures (6 tests)

**File:** `test/kernel/services/external_subtitle_test.dart`
**Root cause:** `state_monitor.dart:126` → `PlaylistStore.dispose()` → `path_provider` MissingPluginException
**Action:** 在 setUp 中添加 path_provider mock

```dart
import 'package:flutter/services.dart';

setUp(() {
  // Mock path_provider to prevent MissingPluginException
  TestDefaultBinaryMessengerBinding.instance.defaultBinaryMessenger
      .setMockMethodCallHandler(
    const MethodChannel('plugins.flutter.io/path_provider'),
    (MethodCall methodCall) async {
      if (methodCall.method == 'getApplicationSupportDirectory') {
        return Directory.systemTemp.createTempSync('app_support').path;
      }
      return null;
    },
  );

  engine = FakeEngine();
  playlist = Playlist();
  controller = PlaybackController(
    engine: engine,
    playlist: playlist,
    onNeedRebuild: () {},
    onError: (_) {},
    subtitleService: SubtitleService(engine),
  );
  tempDir = Directory.systemTemp.createTempSync('subtitle_test_');
});

tearDown(() {
  // 清除 mock
  TestDefaultBinaryMessengerBinding.instance.defaultBinaryMessenger
      .setMockMethodCallHandler(
    const MethodChannel('plugins.flutter.io/path_provider'),
    null,
  );
  controller.dispose();
  engine.dispose();
  try {
    tempDir.deleteSync(recursive: true);
  } on Exception {
    // ignore cleanup failures
  }
});
```

**Why:** PlaylistStore.dispose() 在 state_monitor.dart:126 被调用，它使用 path_provider 保存播放列表。测试环境需要 mock 这个平台通道。
