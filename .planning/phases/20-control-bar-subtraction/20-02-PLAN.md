# Phase 20 Gap Closure: Fix External Subtitle Test Race Condition

## Goal

修复 `external_subtitle_test.dart` 中 6 个因异步竞态条件导致的测试失败，使 SC2 达标（905+ tests passing, 0 failures）。

## Context

**Verification result (2026-07-04):** 3/4 criteria passed. SC2 failed — 899 passed, 6 failed.

**Root cause:** `PlaybackNavigator.playIndex()` 在 `playback_navigator.dart:54` 使用 `unawaited()` 触发 `SubtitleService.detectAndLoad()`（fire-and-forget 设计，避免阻塞播放启动）。测试中 `await playIndex(0)` 返回后，`detectAndLoad` 仍在异步执行文件系统 I/O。测试立即断言 `setExternalSubtitleCallCount == 1`，但异步工作尚未完成 → `Actual: <0>`。随后 `tearDown` 删除临时目录，仍在运行的 `detectAndLoad` 触发 `PathNotFoundException`。

**为什么 `unawaited` 是正确的：** 生产环境中，字幕检测不应阻塞播放启动。这是有意的 fire-and-forget 设计。问题仅在测试中——测试需要等待异步工作完成。

## Success Criteria

1. `flutter test test/kernel/services/external_subtitle_test.dart` — 9 tests, 0 failures
2. `flutter test` — 全量测试 905+ passing, 0 failures

## Tasks

### Task 1: Add async wait to external_subtitle_test.dart

**File:** `test/kernel/services/external_subtitle_test.dart`

**Problem:** 每个测试在 `await playIndex(0)` 后立即断言，但 `detectAndLoad` 是异步的。

**Fix:** 在 `await playIndex(0)` 后添加 `await Future<void>.delayed(const Duration(milliseconds: 200))`，给异步文件系统 I/O 足够时间完成。

**修改的测试方法（6 个）：**
1. `detects .srt file with matching base name` (line 80-82)
2. `detects .ass file with matching base name` (line 90-92)
3. `detects .ssa file with matching base name` (line 100-102)
4. `detects .vtt file with matching base name` (line 110-112)
5. `detects subtitle with language tag (movie.en.srt)` (line 120-122)
6. `loads only the first matching subtitle` (line 157-159)

**Pattern (每个测试相同):**
```dart
// Before:
await controller.playIndex(0);
expect(engine.setExternalSubtitleCallCount, 1);

// After:
await controller.playIndex(0);
// Wait for fire-and-forget detectAndLoad to complete
await Future<void>.delayed(const Duration(milliseconds: 200));
expect(engine.setExternalSubtitleCallCount, 1);
```

**Why 200ms:** `detectAndLoad` 做 `Directory.list()` 文件系统 I/O。测试环境通常 <10ms，200ms 提供 20x 安全余量，避免 CI 环境 flaky。
