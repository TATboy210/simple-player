## Flutter 3.44.6 SDK Bug 诊断

**症状:** 所有 `flutter test` 编译失败，错误在 `star_border.dart:535-537`：
```
The getter 'Matrix4' isn't defined for the type '_StarGenerator'
```

**根因:** `star_border.dart` 第 13 行 `import 'package:vector_math/vector_math_64.dart' show Matrix4;` 目标 URI 不存在。
- vector_math 2.2.0 已安装在 pub cache (`C:/Users/35490/AppData/Local/Pub/Cache/hosted/pub.dev/vector_math-2.2.0`)
- Flutter SDK pubspec.yaml 声明了 `vector_math: 2.2.0` 依赖
- 但 `D:/flutter/packages/flutter/.dart_tool/` 中只有 `pub/` 目录，无 `package_config.json`
- 导致 SDK 内部文件无法解析 `package:vector_math` URI

**影响范围:** 所有依赖 Material widgets 的测试编译（即所有 flutter test）

**修复方案:**
1. (首选) 在 Flutter SDK 目录运行 `dart pub get` 生成 package_config.json
2. (备选) 手动创建 package_config.json 指向 pub cache 中的 vector_math
3. (兜底) 升级 Flutter SDK 到修复版本

</bug_analysis>
