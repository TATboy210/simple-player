# Wave 4 Plan 02: Window Manager Abstraction — Dependency Injection

## Objective

将 `WindowService` 对 `window_manager` 包和 `Win32DisplayEnumerator` 的直接依赖改为构造函数注入，使测试可以注入假实现。

**Purpose:** 解耦 WindowService 与平台特定实现，为跨平台移植做准备。
**Output:** WindowService 通过构造函数接收平台依赖，main.dart 负责组装真实实现。

## Context

当前状态:
- `WindowService` 直接导入 `package:window_manager/window_manager.dart`
- `WindowService` 直接导入 `Win32DisplayEnumerator`
- `WindowService` 实现 `WindowListener` 接口（来自 window_manager）
- `main.dart` 创建 `WindowService()` 无参数
- `WindowService.init()` 内部调用 `windowManager.ensureInitialized()`

关键约束:
- 保持 `WindowBridge` 接口不变（UI 层依赖）
- 保持 `WindowService` 的 `WindowListener` 实现（OS 回调驱动状态）
- 测试中已有 `FakeWindowService` 实现 `WindowBridge`

## Tasks

### Task 1: WindowService 构造函数注入 DisplayEnumerator

**文件:**
- `lib/kernel/bridge/window_service.dart`
- `lib/main.dart`

**Action:**
将 `WindowService` 对 `Win32DisplayEnumerator` 的直接依赖改为构造函数注入:

1. 修改 `lib/kernel/bridge/window_service.dart`:
   - 移除 `import 'win32/win32_display_enumerator.dart'`
   - 添加 `import 'display_enumerator.dart'`
   - 构造函数添加 `DisplayEnumerator? displayEnumerator` 参数:
     ```dart
     WindowService({DisplayEnumerator? displayEnumerator})
         : _displayEnumerator = displayEnumerator ?? Win32DisplayEnumerator();
     ```
   - 添加 `final DisplayEnumerator _displayEnumerator;` 字段
   - `init()` 方法中 `Win32DisplayEnumerator.enumerateDisplays()` 改为 `_displayEnumerator.enumerateDisplays()`

2. 修改 `lib/main.dart`:
   - 导入 `Win32DisplayEnumerator`
   - 创建 WindowService 时传入真实实现:
     ```dart
     final windowService = WindowService(
       displayEnumerator: Win32DisplayEnumerator(),
     );
     ```

3. 更新 `test/unit/kernel/bridge/window_service_test.dart`:
   - 如有直接测试 WindowService（非 FakeWindowService），注入假 DisplayEnumerator

**Verify:**
```bash
flutter test test/unit/kernel/bridge/window_service_test.dart
flutter analyze
```

**Done:**
- `WindowService` 不再直接导入 `Win32DisplayEnumerator`
- 通过构造函数注入 `DisplayEnumerator`
- `main.dart` 传入真实实现
- 测试通过

### Task 2: WindowService 初始化方法参数化

**文件:**
- `lib/kernel/bridge/window_service.dart`
- `lib/main.dart`

**Action:**
将 `WindowService.init()` 中对 `windowManager` 的直接调用抽象为可注入的操作:

1. 修改 `lib/kernel/bridge/window_service.dart`:
   - 添加 `WindowManagerOps` 抽象接口（在同文件或新文件）:
     ```dart
     abstract class WindowManagerOps {
       Future<void> ensureInitialized();
       Future<void> waitUntilReadyToShow(WindowOptions options, VoidCallback callback);
       Future<Offset> getPosition();
       Future<Size> getSize();
       Future<void> setBounds(Rect? bounds, {Offset? position, Size? size});
       Future<void> center();
       Future<void> show();
       Future<void> focus();
       Future<void> maximize();
       Future<void> unmaximize();
       Future<void> minimize();
       Future<void> setFullScreen(bool value);
       Future<void> setAspectRatio(double ratio);
       Future<void> setAlwaysOnTop(bool value);
       Future<void> close();
       Future<void> destroy();
       Future<void> startDragging();
       void addListener(WindowListener listener);
       void removeListener(WindowListener listener);
     }
     ```
   - 添加 `RealWindowManagerOps` 实现类，委托给 `windowManager`
   - 构造函数添加 `WindowManagerOps? windowOps` 参数
   - `init()` 和其他方法使用 `_windowOps` 而非直接 `windowManager`

2. 修改 `lib/main.dart`:
   - 创建 WindowService 时传入 `RealWindowManagerOps()`

3. 创建 `test/unit/kernel/bridge/window_manager_ops_test.dart`:
   - 测试 `RealWindowManagerOps` 的基本行为（如果可测试）

**Verify:**
```bash
flutter test
flutter analyze
```

**Done:**
- `WindowService` 不再直接依赖 `windowManager` 全局变量
- 通过 `WindowManagerOps` 接口抽象窗口操作
- 测试可以注入假实现
- 所有现有测试通过
