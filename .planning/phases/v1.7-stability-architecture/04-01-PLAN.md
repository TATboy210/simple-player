# Wave 4 Plan 01: Platform Abstraction Layer — Display Enumerator

## Objective

将 `Win32DisplayEnumerator` 抽象为平台无关的 `DisplayEnumerator` 接口，使 `ScreenUtils` 和 `FullscreenController` 不再直接依赖 Win32 FFI。

**Purpose:** 为跨平台移植做准备，macOS/Linux 只需实现 `DisplayEnumerator` 接口。
**Output:** `DisplayEnumerator` 抽象接口 + 现有代码重构为依赖接口。

## Context

当前状态:
- `Win32DisplayEnumerator` 是 Win32 特定的 FFI 实现（`lib/kernel/bridge/win32/win32_display_enumerator.dart`）
- `ScreenUtils` 直接导入并使用 `Win32DisplayInfo` 类型
- `FullscreenController._buildExitSnapshot()` 直接调用 `Win32DisplayEnumerator.enumerateDisplays()`
- `WindowService.init()` 直接调用 `Win32DisplayEnumerator.enumerateDisplays()`
- 已有 `PlatformFullscreen` 接口模式可参考

关键约束:
- 不引入 win32 包，使用 dart:ffi + DynamicLibrary.open
- 保持现有测试通过（666 tests）
- `Win32DisplayInfo` 数据类需要泛化为 `DisplayInfo`

## Tasks

### Task 1: 创建 DisplayEnumerator 抽象接口

**文件:** `lib/kernel/bridge/display_enumerator.dart`

**Action:**
创建平台无关的显示器枚举接口:

1. 新建 `lib/kernel/bridge/display_enumerator.dart`:
   - 定义 `DisplayInfo` 数据类（从 `Win32DisplayInfo` 泛化）:
     ```dart
     class DisplayInfo {
       const DisplayInfo({
         required this.bounds,
         required this.workArea,
         required this.isPrimary,
       });
       final Rect bounds;
       final Rect workArea;
       final bool isPrimary;
     }
     ```
   - 定义 `DisplayEnumerator` 抽象接口:
     ```dart
     abstract class DisplayEnumerator {
       List<DisplayInfo> enumerateDisplays();
       DisplayInfo? getDisplayForWindow(int hwnd);
       DisplayInfo? getCurrentDisplay();
     }
     ```

2. 修改 `lib/kernel/bridge/win32/win32_display_enumerator.dart`:
   - 让 `Win32DisplayEnumerator` 实现 `DisplayEnumerator` 接口
   - 保留 `Win32DisplayInfo` 作为向后兼容别名: `typedef Win32DisplayInfo = DisplayInfo;`
   - 内部实现不变，只添加 `implements DisplayEnumerator`

3. 新建 `test/kernel/bridge/display_enumerator_test.dart`:
   - 测试 `DisplayInfo` 数据类的构造和相等性
   - 测试 `DisplayInfo.toString()` 输出

**Verify:**
```bash
flutter test test/kernel/bridge/display_enumerator_test.dart
flutter test test/kernel/bridge/win32_display_enumerator_test.dart
```

**Done:**
- `DisplayEnumerator` 接口定义完成
- `Win32DisplayEnumerator` 实现该接口
- `Win32DisplayInfo` 作为类型别名保持向后兼容
- 新测试通过

### Task 2: ScreenUtils 和 FullscreenController 依赖抽象接口

**文件:**
- `lib/kernel/utils/screen_utils.dart`
- `lib/kernel/bridge/fullscreen_controller.dart`
- `test/kernel/utils/screen_utils_test.dart`

**Action:**
将 `ScreenUtils` 和 `FullscreenController` 的依赖从 `Win32DisplayEnumerator` 改为 `DisplayEnumerator`:

1. 修改 `lib/kernel/utils/screen_utils.dart`:
   - 导入从 `import '../bridge/win32/win32_display_enumerator.dart'` 改为 `import '../bridge/display_enumerator.dart'`
   - `clampToNearestMonitor` 参数类型从 `List<Win32DisplayInfo>` 改为 `List<DisplayInfo>`
   - 内部方法 `_findContainingDisplay` 和 `_findNearestDisplay` 参数类型同步更新

2. 修改 `lib/kernel/bridge/fullscreen_controller.dart`:
   - 导入从 `import 'win32/win32_display_enumerator.dart'` 改为 `import 'display_enumerator.dart'`
   - 构造函数添加可选的 `DisplayEnumerator? displayEnumerator` 参数
   - `_buildExitSnapshot()` 使用注入的 `DisplayEnumerator`（默认回退到 `Win32DisplayEnumerator`）
   - 保持 `Win32DisplayEnumerator` 作为默认值，确保现有行为不变

3. 更新 `test/kernel/utils/screen_utils_test.dart`:
   - 导入改为 `import 'package:simple_player_flutter/kernel/bridge/display_enumerator.dart'`
   - `Win32DisplayInfo` 引用改为 `DisplayInfo`

**Verify:**


**Done:**
- `ScreenUtils` 不再直接依赖 Win32 特定类型
