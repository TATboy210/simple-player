Replace the `AnimatedSwitcher` block (around line 218-224) with a custom transition that slides content left/right based on tab index change:

1. Track previous tab index to determine slide direction. Add a `int _previousIndex` field initialized to 0. Update it in the `setState` callback when tab changes.

2. Replace `AnimatedSwitcher(duration: ...)` with `AnimatedSwitcher` using a custom `transitionBuilder`:
   - Use `SlideTransition` with `Offset` tween: incoming tab slides from right (+0.3, 0) if moving forward, from left (-0.3, 0) if moving backward.
   - Combine with `FadeTransition` (opacity 0→1) for smooth crossfade.
   - Duration: `Duration(milliseconds: Tokens.durationSlide)` (300ms).

3. Give the new `AnimatedSwitcher` a `key: ValueKey(_selectedIndex)` to force rebuild on tab change.

**B. Bottom buttons — hover/press feedback + accent glow:**

Replace the `_BottomButton` StatelessWidget (around line 295-335) with an interactive version:

1. Convert `_BottomButton` to StatefulWidget with `SingleTickerProviderStateMixin` (same pattern as GlassButton in glass_container.dart).

2. Add scale animation: `AnimationController` with `lowerBound: Tokens.pressScale` (0.98), `upperBound: Tokens.hoverScale` (1.02), initial value 1.0. Duration: `Tokens.durationFast` (80ms).

3. Wrap in `MouseRegion` for hover detection: `onEnter` → animate to `Tokens.hoverScale`, `onExit` → animate to 1.0.

4. Add `GestureDetector` or `InkWell` for press: `onTapDown` → set to `Tokens.pressScale`, `onTapUp`/`onTapCancel` → animate back to 1.0.

5. Wrap content in `ScaleTransition(scale: _scaleAnim, child: ...)`.

6. **Primary button accent glow:** When `primary: true`, add a subtle `BoxShadow` to the container decoration:

7. Keep existing `InkWell` hover color (`Tokens.bgHover`) and `borderRadius` from current implementation.

Do NOT change the button labels, layout, or OK/Cancel/Apply logic — only visual feedback.
