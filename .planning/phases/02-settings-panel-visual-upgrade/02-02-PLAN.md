  <action>
Create a new reusable widget `AnimatedSectionList` in `lib/ui/shared/animated_section_list.dart`:

1. **Class definition:** `AnimatedSectionList extends StatefulWidget` with constructor parameters:
   - `List<Widget> children` — the content sections to animate
   - `Duration staggerDelay` — delay between each child's animation start (default: `Duration(milliseconds: 50)`)
   - `Duration animationDuration` — duration of each child's fade-in (default: `Duration(milliseconds: Tokens.durationSlide)` which is 300ms)

2. **Animation logic:** Use `SingleTickerProviderStateMixin`. In `initState`, create an `AnimationController` with `vsync` and `duration` equal to total animation time (staggerDelay * children.length + animationDuration). Call `controller.forward()` in `initState`.

3. **Builder:** Use `AnimatedBuilder` with the controller. For each child at index `i`:
   - Calculate start time: `staggerDelay * i / totalDuration` (normalized 0.0-1.0)
   - Calculate end time: `(staggerDelay * i + animationDuration) / totalDuration`
   - Create interval: `Interval(start, end, curve: Curves.easeOut)`
   - Apply `FadeTransition` with opacity animated by this interval
   - Wrap each child in `AnimatedOpacity` or use `FadeTransition(opacity: Tween<double>(begin: 0, end: 1).animate(CurvedAnimation(parent: controller, curve: interval)), child: child)`

4. **Key handling:** Use `GlobalKey<AnimatedSectionListState>` or expose a `reset()` method so the animation can replay when the parent tab changes. Alternatively, use a `Key` on the widget to force re-creation on tab switch (simpler approach — parent passes `Key('tab-$index')` to force rebuild).

5. **Dispose:** Properly dispose the AnimationController in `dispose()`.

6. **Performance:** Keep the implementation lightweight — no complex stagger libraries, just simple Interval-based fade. The widget should be <100 lines.

7. **Comments:** Add `///` doc comment explaining the widget's purpose and usage pattern.

Wrap each tab's content sections with `AnimatedSectionList` to add staggered reveal on tab switch:

**Pattern for each tab:**

In each tab's `build` method, the root widget is typically a `ListView` with multiple children (GlassContainer sections, SettingRow widgets, etc.). Wrap the `ListView.children` list with `AnimatedSectionList`:

```dart
// BEFORE
ListView(
  padding: EdgeInsets.zero,
  children: [
    GlassContainer(...),
    GlassContainer(...),
  ],
)

// AFTER
ListView(
  padding: EdgeInsets.zero,
  children: AnimatedSectionList(
    children: [
      GlassContainer(...),
      GlassContainer(...),
    ],
  ),
)
```

**Important:** The `AnimatedSectionList` should be the `children` of `ListView`, not wrapped around `ListView`. This ensures the stagger animation applies to each section individually.
