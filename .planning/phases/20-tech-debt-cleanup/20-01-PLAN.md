## Tasks

### Task 1: Fix PlayerServices.create error

**File:** `lib/features/player/player_services.dart`
**Action:** 添加静态 `create()` 工厂方法

```dart
static Future<PlayerServices> create({
  required WindowBridge windowService,
  EngineState? engineOverride,
}) async {
  final services = PlayerServices(
    windowService: windowService,
    engineOverride: engineOverride,
  );
  await services.init();
  return services;
}
```

**Why:** PlayerViewModel.init() 调用 `PlayerServices.create()` 但方法不存在。这是最简单的修复——添加工厂方法而不是修改所有调用者。

### Task 3: Migrate deprecated Color APIs (18 issues)

**Files:** `lib/ui/theme/tokens.dart`, `test/unit/theme/contrast_test.dart`, `test/widget/tokens_test.dart`
**Action:** 迁移到 Flutter 3.x Color API

| Deprecated | Replacement |
|-----------|-------------|
| `color.value` | `color.toARGB32()` |
| `color.alpha` | `(color.a * 255).round()` |
| `color.red` | `(color.r * 255).round()` |
| `color.green` | `(color.g * 255).round()` |
| `color.blue` | `(color.b * 255).round()` |

**Why:** Flutter 3.27+ 弃用了整数访问器，新的 double-based API 更安全（不会溢出）。

### Task 4: Fix showDialog type inference warnings (2 issues)
