## Root Cause Analysis

### RC-1: PlayerServices.create error

`player_view_model.dart:62` 调用 `PlayerServices.create()` 但 `player_services.dart` 只有构造函数 + `init()` 方法，没有静态工厂方法。

### RC-2: External subtitle test failures (双重根因)

**根因 A — unawaited 竞态条件：**
`PlaybackNavigator.playIndex()` 通过 `unawaited()` 调用 `SubtitleService.detectAndLoad()`（fire-and-forget）。测试在 `controller.playIndex(0)` 返回后立即断言 `engine.setExternalSubtitleCallCount`，但异步字幕检测尚未完成。

```dart
// playback_navigator.dart:53-59
unawaited(
  _controller.subtitleService?.detectAndLoad(subtitlePath).catchError(
    (Object e) { log.d('Subtitle detection failed: $e'); },
  ),
);
```

**根因 B — MissingPluginException 噪声：**
`StateMonitor.dispose()` → `PlaylistStore.dispose()` → `getApplicationSupportDirectory()` 在测试环境中抛出 MissingPluginException。

### RC-3: overridden_fields (24) — 字段遮蔽，不是覆盖

`EngineState` mixin 定义了 12 个 concrete `final ValueNotifier` 字段。`FvpEngine` 和 `FakeEngine` 重新声明了这些字段，产生**字段遮蔽**（shadowing）—— 创建了两个独立的存储槽。正确的修复是**删除**重复字段，让类使用 mixin 的字段。

### RC-4: unnecessary_import (12)

`engine_state.dart` 通过 `export` 重新导出了所有类型。`fvp_engine.dart` 和 `mock_engine.dart` 同时 import 了 `engine_state.dart` 和子模块，导致重复。

### RC-5: deprecated_member_use (18)

Flutter 3.27+ 弃用了 Color 的整数访问器（`.value`, `.alpha`, `.red`, `.green`, `.blue`），新的 double-based API（`.a`, `.r`, `.g`, `.b`, `.toARGB32()`）更安全。
