    - Constructor params: required RssProvider rssProvider, required Clock clock, int thresholdBytes = 50 * 1024 * 1024 (D9), int maxHistory = 200 (D9), Duration interval = const Duration(seconds: 30) (D9), KernelLogger? logger, void Function(MemorySnapshot)? onTick
    - Constructor body calls _startImpl() (D5 constructor-start)
