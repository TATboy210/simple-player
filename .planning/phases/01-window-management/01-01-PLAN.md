window_channel.cpp:
- Register method:
  - Create MethodChannel "com.simple_player/window" with StandardMethodCodec
  - Set MethodCallHandler to HandleMethodCall
  - Create EventChannel "com.simple_player/window_events" with StandardMethodCodec
  - Set StreamHandler with onListen (store event_sink_) and onCancel (set event_sink_ = null)
- HandleMethodCall: dispatch by call.method_name():
  - "setFullscreen": extract bool 'fullscreen', call Win32 SetWindowPos to cover monitor or restore. Save/restore window rect. Use SWP_FRAMECHANGED. Set is_fullscreen_. SendEvent("onFullscreenChange", {fullscreen: bool}).
  - "setAlwaysOnTop": extract bool 'alwaysOnTop', call SetWindowPos with HWND_TOPMOST or HWND_NOTOPMOST. result->Success().
  - "setSize": extract double 'width','height', call SetWindowPos with SWP_NOZORDER|SWP_NOMOVE. result->Success().
  - "setPosition": extract double 'x','y', call SetWindowPos with SWP_NOZORDER|SWP_NOSIZE. result->Success().
  - "setMinSize": extract double 'width','height', store as min_width_/min_height_. Used in WM_GETMINMAXINFO handling. result->Success().
  - "setFrameless": extract bool 'frameless', set is_frameless_. Apply/remove WS_THICKFRAME style via SetWindowLongPtr(GWL_STYLE). result->Success().
  - "getTitleBarBounds": return EncodableMap {x, y, width, height} based on window rect and 32px title bar height (D-16).
  - Unknown method: result->NotImplemented().
- HitTest method (stub for now — full implementation in Plan 02):
  - If !is_frameless_ return HTCLIENT (pass through to DefWindowProc)
  - Return HTCLIENT as placeholder
- OnResize: get window rect via GetWindowRect, SendEvent("onResize", {width, height})
- OnClose: SendEvent("onClose", {})
- SendEvent: if event_sink_ is not null, send EncodableMap with "event" key + data
- All Win32 API calls wrapped in error checking

WindowService class:
- Imports: dart:async, package:flutter/foundation.dart (for ValueNotifier, Size), package:flutter/services.dart (MethodChannel, EventChannel, PlatformException)
- Import kernel/utils/log.dart for logger
- Static const: _channel = MethodChannel('com.simple_player/window'), _eventChannel = EventChannel('com.simple_player/window_events')
- Private: bool _disposed = false, StreamSubscription<dynamic>? _eventSubscription
- State (ValueNotifier pattern from FvpEngine):
  - final ValueNotifier<bool> isFullscreen = ValueNotifier(false)
  - final ValueNotifier<bool> isAlwaysOnTop = ValueNotifier(false)
  - final ValueNotifier<bool> isMaximized = ValueNotifier(false)
  - final ValueNotifier<Size> windowSize = ValueNotifier(const Size(960, 540))
- init(): subscribe to _eventChannel.receiveBroadcastStream().listen(_handleEvent, onError: log.e)
- _handleEvent(dynamic event): cast to Map, switch on map['event']:
  - 'onResize': windowSize.value = Size(width, height)
  - 'onFullscreenChange': isFullscreen.value = map['fullscreen'] as bool
  - 'onMove': (log for now, no state to update)
  - 'onClose': (log for now)
  - 'onMinimize': (log for now)
- _guardedCall(String name, Map<String, dynamic> args) async: if _disposed return; try await _channel.invokeMethod(name, args); on Exception catch (e) log.e('WindowService.$name failed', error: e)
- Public methods (each calls _guardedCall):
  - setFullscreen(bool value) => _guardedCall('setFullscreen', {'fullscreen': value})
  - setAlwaysOnTop(bool value) => _guardedCall('setAlwaysOnTop', {'alwaysOnTop': value})
  - setSize(double w, double h) => _guardedCall('setSize', {'width': w, 'height': h})
  - setPosition(double x, double y) => _guardedCall('setPosition', {'x': x, 'y': y})
  - setMinSize(double w, double h) => _guardedCall('setMinSize', {'width': w, 'height': h})
  - setFrameless(bool value) => _guardedCall('setFrameless', {'frameless': value})
  - getTitleBarBounds() async: if _disposed return Rect.zero; try final result = await _channel.invokeMethod('getTitleBarBounds'); cast to Map; return Rect.fromLTWH(...); on Exception catch (e) { log.e(...); return Rect.zero; }
- dispose(): _disposed = true; _eventSubscription?.cancel(); dispose all 4 ValueNotifiers
