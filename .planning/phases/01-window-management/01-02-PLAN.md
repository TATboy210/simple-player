Implement the frameless window logic in window_channel.cpp per D-08, D-09, D-10.

1. Complete the HitTest method (was stubbed in Plan 01):
   - If !is_frameless_ return -1 (let DefWindowProc handle)
   - Convert lParam screen coords to client coords via ScreenToClient
   - Get client rect via GetClientRect (not GetWindowRect)
   - Edge detection with 8px width (D-09):
     - bool left = pt.x < edge, right = pt.x >= rc.right - edge
     - bool top = pt.y < edge, bottom = pt.y >= rc.bottom - edge
     - if (top && left) return HTTOPLEFT
     - if (top && right) return HTTOPRIGHT
     - if (bottom && left) return HTBOTTOMLEFT
     - if (bottom && right) return HTBOTTOMRIGHT
     - if (left) return HTLEFT
     - if (right) return HTRIGHT
     - if (top) return HTTOP
     - if (bottom) return HTBOTTOM
   - Title bar drag region (D-10): if (pt.y < 32) return HTCAPTION (D-16: 32px height)
   - Otherwise return HTCLIENT

2. Add HandleNcCalcSize method to WindowChannel:
   - If wParam == TRUE and is_frameless_: cast lParam to NCCALCSIZE_PARAMS*, adjust rgrc[0].top += 1 (minimal inset for resize cursor, preserves WS_THICKFRAME for snap per D-31), return 0
   - Otherwise return -1 (default handling)

3. Add fullscreen implementation to SetFullscreen command handler:
   - Save current window rect + style before entering fullscreen
   - If entering fullscreen:
     - Get monitor rect via MonitorFromWindow + GetMonitorInfo
     - SetWindowPos to cover entire monitor with SWP_FRAMECHANGED
     - Set is_fullscreen_ = true
   - If exiting fullscreen:
     - Restore saved rect + style
     - SetWindowPos with SWP_FRAMECHANGED
     - Set is_fullscreen_ = false
   - Re-apply rounded corners (D-21) after fullscreen transition via ApplyRoundedCorners or DwmSetWindowAttribute

4. Update setFrameless command handler:
   - When setting frameless: add WS_THICKFRAME style (preserves resize + snap per D-31) via SetWindowLongPtr(GWL_STYLE)
   - When unsetting frameless: restore WS_OVERLAPPEDWINDOW style
   - Call SetWindowPos with SWP_FRAMECHANGED to apply style change
   - Set is_frameless_ flag

5. Add WM_GETMINMAXINFO handling to enforce minimum window size (D-19: > 640x360):
   - In a new OnGetMinMaxInfo method: cast lParam to MINMAXINFO*, set ptMinTrackSize to stored min_width_/min_height_ (default 640x360)
   - Return 0 to indicate handled
