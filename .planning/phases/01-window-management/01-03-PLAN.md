CustomTitleBar widget:
- Constructor: required WindowService windowService
- Height: 32px (Tokens.titleBarHeight)

  - Leading: Padding with app name Text("Simple Player", style: TextStyle using Tokens.fontCaption, Tokens.weightMedium, Tokens.textPrimary)

  - Trailing: Row of 3 buttons (_TitleBarButton widgets)

_TitleBarButton private widget:
- Constructor: required IconData icon, required VoidCallback onPressed, bool isClose = false
- State: ValueNotifier<bool> _hovered for hover tracking
- Build: MouseRegion(onEnter/onExit toggling _hovered) wrapping GestureDetector(onTap: onPressed)
- Visual: ValueListenableBuilder on _hovered:
  - Not hovered: transparent background, Tokens.textSecondary icon color
  - Hovered: isClose ? Tokens.closeHoverBg background : Tokens.titleBarHover background, Tokens.textPrimary icon color
  - Width: Tokens.titleBarButtonWidth (36px), height: 32px
  - Icon: Icon widget using Tokens.iconSm size

Button actions (call WindowService methods):
- Minimize: WindowManager.minimizeWindow via platform (or use WindowService if method added — for now, skip minimize as no MethodChannel command exists for it. Add a minimize method to WindowService that calls _guardedCall('minimize', {}))
  - Actually, minimize needs C++ support. Add a 'minimize' command to WindowChannel::HandleMethodCall that calls ShowWindow(hwnd_, SW_MINIMIZE). Add minimize() method to WindowService.
- Maximize/Restore: Toggle — if isMaximized, call setSize to restore; else call setFullscreen or use Win32 maximize
  - Actually, maximize needs C++ support too. Add 'maximize' command to WindowChannel that calls ShowWindow(hwnd_, SW_MAXIMIZE) and sends onMaximize event. Add 'restore' command that calls ShowWindow(hwnd_, SW_RESTORE). Add maximize()/restore() to WindowService. Use ValueListenableBuilder on isMaximized to show maximize vs restore icon.
- Close: WindowManager.closeWindow via platform
  - Add 'close' command to WindowChannel that calls PostMessage(hwnd_, WM_CLOSE, 0, 0). Add close() to WindowService.

Also add to WindowChannel: handle 'minimize', 'maximize', 'restore', 'close' method calls.

Fullscreen visibility (D-17): Wrap entire CustomTitleBar in ValueListenableBuilder<bool> on windowService.isFullscreen. If isFullscreen, return SizedBox.shrink(). Otherwise return the title bar content.

Double-click (D-12): Wrap the title bar Row in GestureDetector(onDoubleTap: toggle maximize/restore). Use isMaximized state to decide.

Background (D-15): Container with transparent background by default. On hover (track via MouseRegion onEnter/onExit at parent level), show Tokens.titleBarBg semi-transparent background.

All visual values from Tokens.* per D-23. No hardcoded colors or sizes.
