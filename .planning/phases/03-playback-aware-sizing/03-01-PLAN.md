2. In `_onStateChanged()` method (currently lines 56-89), add aspect ratio logic BEFORE the existing pause check. The new method body should be:

   ```dart
   void _onStateChanged() {
     final state = engine.state.value;

     // 播放时锁定宽高比到视频原生比例（per WP-01, WP-03）
     if (state == MediaState.playing) {
       final ratio = engine.aspectRatio.value;
       if (ratio > 0) {
         AspectRatioService.I.matchVideo(ratio);
       }
     }

     // 停止/空闲/完成/错误时解锁宽高比（per WP-04）
     // 暂停保持锁定 — 用户暂停不应对窗口行为产生干扰
     if (state == MediaState.stopped ||
         state == MediaState.idle ||
         state == MediaState.completed ||
         state == MediaState.error) {
       AspectRatioService.I.unlock();
     }

     // 暂停时保存断点位置（existing logic, unchanged）
     if (state == MediaState.paused) {
       final idx = playlist.currentIndex;
       if (idx >= 0) {
         playlist.updatePosition(
           idx,
           engine.position.value,
           engine.duration.value,
         );
         savePlaylist();
       }
       return;
     }

     if (state != MediaState.completed) return;

     // auto-play logic (existing, unchanged)
     if (playlist.mode == PlayMode.loopSingle) {
       final idx = playlist.currentIndex;
       if (idx >= 0) {
         playIndex(idx).catchError((e) {
           debugPrint('StateMonitor loopSingle replay failed: $e');
           onError?.call(e);
         });
       }
     } else {
       playNext().catchError((e) {
         debugPrint('StateMonitor auto-advance failed: $e');
         onError?.call(e);
       });
     }
   }
   ```

   Key design decisions:
   - Aspect ratio lock fires on `playing` state (not `loading`), because `engine.aspectRatio.value` is set during `open()` before `play()` is called
   - `paused` does NOT unlock — pausing is a transient state, the user expects the window to stay locked
   - `seeking` and `buffering` are transient states that don't affect the lock
   - `AspectRatioService.I.matchVideo()` is async but we don't await it — fire-and-forget matches the existing pattern for non-critical side effects. The MethodChannel call will complete in the background.
   - We read `engine.aspectRatio.value` synchronously (it's already set by the time `play()` triggers `state = playing`)
