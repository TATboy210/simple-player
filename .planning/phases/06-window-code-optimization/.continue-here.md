## Key Technical Detail: FFI Fullscreen

window_manager 的 `setFullScreen(true)` 只移除 `WS_THICKFRAME | WS_MAXIMIZEBOX`，保留 `WS_CAPTION`（0x00C00000）。`WS_CAPTION = WS_BORDER | WS_DLGFRAME` 为标题栏保留 ~32px 非客户区，导致窗口看起来像"最大化"而非全屏。

修复方案：FFI 直接调用 Win32 API：
- `GetWindowLongPtrW` / `SetWindowLongPtrW` — 移除 WS_CAPTION
- `MonitorFromWindow` + `GetMonitorInfoW` — 获取显示器尺寸
- `SetWindowPos` — 覆盖整个显示器区域
- 退出时恢复原始样式和窗口位置
