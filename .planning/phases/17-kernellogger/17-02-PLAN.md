  <action>
For each of the 24 kernel files that import `log.dart`, make exactly TWO changes (per D10 — "keep final log = ..., change type only"):

**Change 1 — Replace import line:**
The import replacement depends on the file's directory location:

- Files in `lib/kernel/utils/` (screen_utils.dart, debug_exporter.dart, path_utils.dart):
  `import 'log.dart';` → `import '../diagnostics/kernel_logger.dart';`

- Files in `lib/kernel/bridge/win32/` (win32_display_enumerator.dart):
  `import '../../utils/log.dart';` → `import '../../diagnostics/kernel_logger.dart';`

- All other files (18 files in engine/, services/, bridge/, persistence/, playlist/, startup/):
  `import '../utils/log.dart';` → `import '../diagnostics/kernel_logger.dart';`

**Change 2 — Replace logger variable declarations:**
Each file declares one or more logger variables. Replace each declaration:

- `final log = Logger('...');` → `final log = KernelLogger.I;`
- `final logEngine = Logger(...)` with PrefixPrinter → `final logEngine = KernelLogger.I;`
- `final logBridge = Logger(...)` with PrefixPrinter → `final logBridge = KernelLogger.I;`

Note: The old declarations use `Logger('name')` or `Logger(printer: PrefixPrinter(...))`. The new declaration is always `KernelLogger.I` regardless of the old logger name. The module prefix that was in PrefixPrinter is already embedded in the call site message strings (e.g., `[DisplayConfig]`, `FvpEngine.`).

**Do NOT change:**
- Any call site lines (log.w(), log.e(), logEngine.e(), logBridge.w(), etc.) — these stay exactly as-is per D11
- Any files outside `lib/kernel/` (app.dart, main.dart, player_feature.dart, deferred_player_feature.dart keep their old imports)
- `lib/kernel/utils/log.dart` itself — it stays as-is for app-level usage

**CRITICAL: Some files have multiple logger variables.** Specifically:
- `fvp_engine.dart` has both `log` and `logEngine` — replace BOTH declarations
- All other files have exactly one logger variable (`log` or `logBridge`)

After all 22 files are migrated, run `flutter analyze` to verify zero compilation errors.
