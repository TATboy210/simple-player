创建 `.github/workflows/release.yml`，按 D-48~D-52 决策：

**触发条件**（D-52: 手动触发 + CI 自动执行）：
- `workflow_dispatch` with input `version` (required, 描述 'Version tag e.g. v1.0.0-rc.1')

**Job: release-windows**
- runs-on: windows-latest
- steps:
  1. `actions/checkout@v4`
  2. `subosito/flutter-action@v2` with `channel: 'stable'` + `cache: true`
  3. `flutter build windows --dart-define=USE_NEW_FULLSCREEN=true`
  4. `dart run msix:create` (使用 pubspec.yaml 中的 msix 配置)
  5. `actions/upload-artifact@v4` — 上传 `build/windows/x64/runner/Release/*.msix`
  6. `softprops/action-gh-release@v2`:
     - tag_name: `${{ github.event.inputs.version }}`
     - prerelease: true
     - files: `build/windows/x64/runner/Release/*.msix`

修改 `pubspec.yaml` 添加 msix 配置（D-49: GitHub Release + MSIX 打包）：
在 pubspec.yaml 末尾追加 msix 配置段：
```yaml
msix_config:
  display_name: Simple Player
  publisher_display_name: Simple Player
  identity_name: com.simpleplayer.app
  msix_version: 1.0.0.0
  logo_path: windows/runner/resources/app_icon.ico
  capabilities: internetClient
```

注意 msix_version 格式为 `x.x.x.x`（4 部分，非语义化版本，D-48 研究 Pitfall 4）。实际发布时通过 workflow input 动态覆盖版本号。
