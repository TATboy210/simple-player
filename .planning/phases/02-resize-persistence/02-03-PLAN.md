<objective>
Fix title bar jitter during window resize by eliminating widget tree mutation, adding RepaintBoundary isolation, and suppressing hover effects during resize.

Purpose: The current CustomTitleBar uses a ValueListenableBuilder that structurally adds/removes ClipRect + BackdropFilter when isResizing toggles. This tree mutation triggers relayout on every toggle boundary, causing visible jitter. Additionally, no RepaintBoundary isolates the title bar from Column relayout during resize, and _TitleBarButton hover setState is not protected during resize.

Output: Production-grade rendering optimization — no visual regression, no functional regression, measurable jitter elimination.

- Flutter AnimatedOpacity: https://docs.flutter.dev/cookbook/animation/opacity-animation
- Flutter RepaintBoundary: https://docs.flutter.dev/tools/devtools/inspector
- Flutter Stack + Positioned: https://docs.flutter.dev/flutter-for/web-devs

**Replace with:**
```dart
return GestureDetector(
  behavior: HitTestBehavior.translucent,
  onPanStart: (_) => wm.startDragging(),
  onDoubleTap: () => wm.toggleMaximize(),
  child: ValueListenableBuilder<bool>(
    valueListenable: wm.isResizing,
    child: content,
    builder: (_, resizing, child) => SizedBox(
      height: Tokens.titleBarHeight,
      child: Stack(
        clipBehavior: Clip.none,
        children: [
          // Blur layer — AnimatedOpacity avoids tree mutation.
          // opacity: 0 → RenderOpacity.needsCompositing = false → GPU blur skipped.
          // 80ms fade-in masks stale-bitmap flash on resize end.
          RepaintBoundary(
            child: AnimatedOpacity(
              opacity: resizing ? 0.0 : 1.0,
              duration: const Duration(milliseconds: Tokens.durationFast),
              child: ClipRect(
                child: BackdropFilter(
                  filter: ui.ImageFilter.blur(
                    sigmaX: Tokens.glassBlurThin,
                    sigmaY: Tokens.glassBlurThin,
                  ),
                  child: const SizedBox.expand(),
                ),
              ),
            ),
          ),
          // Content layer — RepaintBoundary isolates from blur dirty marks.
          Positioned.fill(
            child: RepaintBoundary(child: child!),
          ),
        ],
      ),
    ),
  ),
);
```

**Key design decisions:**
- `SizedBox(height: Tokens.titleBarHeight)` wraps the Stack to provide a tight height constraint. The Stack itself has no intrinsic height.
- `RepaintBoundary` on blur layer isolates expensive BackdropFilter repaints from content.
- `RepaintBoundary` on content layer isolates content from blur dirty marks.
- `AnimatedOpacity(duration: 80ms)` uses `Tokens.durationFast` — imperceptible fade that masks stale-bitmap flash.
- `SizedBox.expand()` inside BackdropFilter fills the blur area — the BackdropFilter captures and blurs the scene behind it.
- `content` is passed via `ValueListenableBuilder.child:` — not rebuilt when isResizing toggles.

Add `isResizing` guard to the `MouseRegion` `onEnter`/`onExit` callbacks in `_TitleBarButtonState`.

**Current code (lines 174-175):**
```dart
onEnter: (_) => setState(() => _hovered = true),
onExit: (_) => setState(() => _hovered = false),
```

**Replace with:**
```dart
onEnter: (_) {
  if (!PlatformService.I.isResizing.value) {
    setState(() => _hovered = true);
  }
},
onExit: (_) {
  if (!PlatformService.I.isResizing.value) {
    setState(() => _hovered = false);
  }
},
```

**Why read `.value` instead of listening:** The button does not need to rebuild when isResizing changes. It only needs to gate the hover callbacks. Reading `.value` synchronously is zero-overhead — no subscription, no rebuild, no listener lifecycle management.
