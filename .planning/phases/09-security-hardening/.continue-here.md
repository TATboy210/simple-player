## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Uri.tryParse empty authority | `Uri.tryParse('http://')` returns hasAuthority=true with empty host | advisory | Always check `host.isNotEmpty` alongside `hasAuthority` |
| Arena not available | `dart:ffi` `using()` doesn't support Arena callback pattern in current version | advisory | Use try/finally blocks for FFI pointer cleanup |
