       ```
       static bool _hasControlCharacters(String path) {
         for (var i = 0; i < path.length; i++) {
           final code = path.codeUnitAt(i);
           if (code < 0x20 && code != 0x00 && code != 0x09) return true;
         }
         return false;
       }
       ```
