  <action>
    修改 `lib/kernel/bridge/window_service.dart`:

    **per D-28:** WindowService.setMode(fullscreen) 内部委托 FullscreenAdapter。

    **per D-29:** WindowService 仅转发 fullscreen，不接管队列/状态机逻辑。

    **per D-31:** feature flag 只在 FullscreenAdapter 内切换实现（legacy/new），不在 WindowService 层加 flag。

    **具体改动:**

    1. 添加构造函数参数 `FullscreenAdapter? fullscreenAdapter`
    2. 保存为 `_fullscreenAdapter` 字段
    3. 修改 `setMode(WindowMode.fullscreen)` 分支:
       - 如果 `_fullscreenAdapter != null`:
         - 调用 `_fullscreenAdapter.setFullscreen(true)` 替代 `fullScreenWindow.setFullScreen(true)`
         - FullscreenAdapter 内部处理队列、状态回读、恢复策略
       - 如果 `_fullscreenAdapter == null`:
         - 保留旧的 `fullScreenWindow.setFullScreen(true)` 作为 fallback
    4. 退出全屏逻辑:
       - `setMode(WindowMode.windowed)` 且当前 mode == fullscreen 时:
         - 如果 `_fullscreenAdapter != null`: 调用 `_fullscreenAdapter.setFullscreen(false)`
         - 否则: `fullScreenWindow.setFullScreen(false)`

    **per D-03:** WindowService.mode 和 FullscreenSnapshot 是两个独立状态源。需要同步:
    - FullscreenAdapter 进入全屏后 → WindowService.mode 设为 WindowMode.fullscreen
    - FullscreenAdapter 退出全屏后 → WindowService.mode 设为 WindowMode.windowed
    - 同步通过监听 FullscreenAdapter.events 实现:
      - `Entered` 事件 → `_state.mode.value = WindowMode.fullscreen`
      - `Left` 事件 → `_state.mode.value = WindowMode.windowed`

    **注意:**
    - 不要删除 `fullscreen_window` 的 import — 旧路径仍需保留
    - `onWindowEnterFullScreen` / `onWindowLeaveFullScreen` 回调保留，但它们现在是二级确认（FullscreenAdapter 的 _waitForConfirmation 会读取这些回调驱动的 mode 变化）
    - 保持 WindowService 的其他功能（init/setAlwaysOnTop/setAspectRatio/minimize/close）不变
  </action>

    **具体改动:**

    1. 创建 FullscreenAdapter 实例:
       ```dart
       const useNewFullscreen = bool.fromEnvironment(
         'USE_NEW_FULLSCREEN',
         defaultValue: false,
       );

       FullscreenAdapter? fullscreenAdapter;
       if (useNewFullscreen) {
         final driver = DesktopFullscreenDriver();
         fullscreenAdapter = DesktopFullscreenAdapter(
           driver: driver,
         );
       }
       ```

    2. 将 fullscreenAdapter 传入 WindowService:
       ```dart
       final windowService = WindowService(
         fullscreenAdapter: fullscreenAdapter,
       );
       ```

    3. 如果 app.dart 有依赖注入容器或 provider，确保 FullscreenAdapter 也被注册供 UI 层使用

    **注意:**
    - `defaultValue: false` — 默认使用旧实现，新实现需要显式开启
    - DesktopFullscreenAdapter 需要 WindowBridge 的回调流。在创建时传入 windowService（它实现了 WindowBridge）
    - 如果 app.dart 的结构不便于直接注入，可以创建一个工厂方法或辅助函数
