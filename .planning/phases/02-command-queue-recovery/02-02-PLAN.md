    **1. 创建 `lib/kernel/bridge/fullscreen_driver.dart`:**

    FullscreenDriver 抽象接口 — 封装平台原生全屏操作，DesktopFullscreenAdapter 通过此接口与窗口管理器交互。

    ```dart
    abstract class FullscreenDriver {
      Future<void> enterFullscreen({int displayId});
      Future<void> leaveFullscreen();
      Future<bool> queryFullscreen();
      Future<Offset> getPosition();
      Future<Size> getSize();
      Future<void> setBounds(Offset? position, Size? size);
      Future<void> maximize();
      Future<void> restore();
      Future<void> focus();
      bool get isMaximized;
    }
    ```

    设计原则:
    - 与 WindowBridge 并列，不继承
    - 每个方法对应一个原生调用，不做状态管理
    - Phase B 使用 windowManager 实现，Phase C 可替换为平台特定驱动

    **2. 创建 `lib/kernel/bridge/desktop_fullscreen_driver.dart`:**

    DesktopFullscreenDriver 实现 FullscreenDriver，使用 `window_manager` 包。

    per D-21: 轮询查询使用 `windowManager.isFullScreen()`。跨平台可用。

    关键实现:
    - `enterFullscreen()` → `windowManager.setFullScreen(true)` (window_manager 跨平台 API)
    - `leaveFullscreen()` → `windowManager.setFullScreen(false)`
    - `queryFullscreen()` → `windowManager.isFullScreen()`
    - `getPosition()` → `windowManager.getPosition()`
    - `getSize()` → `windowManager.getSize()`
    - `setBounds()` → `windowManager.setBounds(null, position: pos, size: size)`
    - `maximize()` → `windowManager.maximize()`
    - `restore()` → `windowManager.restore()`
    - `focus()` → `windowManager.focus()`
    - `isMaximized` → 需要从 WindowState.mode 读取（WindowBridge.mode.value.isMaximized），或通过 `windowManager.isMaximized()` 查询

    注意: 使用 `window_manager` 包（已在项目依赖中），不要使用 `fullscreen_window` 包。
    `fullscreen_window` 只在旧实现路径中使用。

    **内部状态:**

    ```dart
    final FullscreenCommandQueue _queue;
    final Map<int, ValueNotifier<FullscreenSnapshot>> _snapshots = {};
    final StreamController<FullscreenEvent> _events = StreamController.broadcast();
    final Map<int, _RestoreSnapshot> _restoreSnapshots = {};
    ```

    **_RestoreSnapshot 私有数据类:**
    ```dart
    final class _RestoreSnapshot {
      const _RestoreSnapshot({
        required this.mode,
        required this.position,
        required this.size,
        this.isMaximized = false,
        this.displayId = 0,
      });
      final WindowMode mode;
      final Offset position;
      final Size size;
      final bool isMaximized;
      final int displayId;
    }
    ```
    per D-22: restoreMode 在调用原生前快照。快照内容: restoreMode + position + size + displayId + isMaximized。
    FullscreenMode 不包含 maximized（只有 windowed/borderless/exclusive），所以 isMaximized 单独记录。

    **setFullscreen 实现流程:**
    1. 获取/创建 snapshot notifier
    2. error 状态自动清理（per D-09）
    3. 如果正在过渡中，返回 BusyTransition（per D-12）
    4. 创建 FullscreenRequest
    5. 调用 `_queue.enqueue(request, executor: _executeCommand)`

    **_executeCommand 回调（队列的 executor）:**
    ```dart
    Future<bool> _executeCommand(FullscreenRequest request) async {
      final notifier = _snapshotFor(request.windowId);
      final current = notifier.value;

      if (request is EnterFullscreen) {
        // D-22: 调用原生前快照
        if (!current.isFullscreen) {
          _captureRestoreSnapshot(request.windowId);
        }
        // D-16: 命令开始执行时更新 phase
        notifier.value = current.copyWith(phase: FullscreenPhase.entering);
        _events.add(FullscreenEvent.enterRequested(targetMode: request.mode));

        // D-25: minimized 状态下先 restore 再全屏
        if (_isWindowMinimized(request.windowId)) {
          await _driver.restore();
          await Future.delayed(const Duration(milliseconds: 100));
        }

        await _driver.enterFullscreen(displayId: request.mode == FullscreenMode.borderless ? 0 : 0);

        // D-19: 三级状态回读
        final confirmed = await _waitForConfirmation(request.windowId, true);

        if (confirmed) {
          notifier.value = notifier.value.copyWith(
            phase: FullscreenPhase.stable,
            effectiveMode: request.mode,
          );
          _events.add(FullscreenEvent.entered(finalMode: request.mode));
          return true;
        } else {
          // D-20: StateDesync — 报错 + 不自动重试，但 snapshot 更新为真实状态
          final actualFullscreen = await _driver.queryFullscreen();
          final actualMode = actualFullscreen ? FullscreenMode.borderless : FullscreenMode.windowed;
          notifier.value = notifier.value.copyWith(
            phase: FullscreenPhase.error,
            effectiveMode: actualMode,
            lastError: FullscreenError.stateDesync(
              expected: request.mode,
              actual: actualMode,
            ),
          );
          _events.add(FullscreenEvent.error(
            error: FullscreenError.stateDesync(
              expected: request.mode,
              actual: actualMode,
            ),
          ));
          return false;
        }
      }

      if (request is LeaveFullscreen) {
        notifier.value = current.copyWith(phase: FullscreenPhase.leaving);
        _events.add(FullscreenEvent.leaveRequested());

        await _driver.leaveFullscreen();

        // D-19: 三级状态回读
        final confirmed = await _waitForConfirmation(request.windowId, false);

        if (confirmed) {
          // D-22~D-25: 恢复策略
          await _restoreFromSnapshot(request.windowId);
          notifier.value = notifier.value.copyWith(
            phase: FullscreenPhase.stable,
            effectiveMode: FullscreenMode.windowed,
            clearError: true,
          );
          _events.add(FullscreenEvent.left());
          return true;
        } else {
          final actualFullscreen = await _driver.queryFullscreen();
          final actualMode = actualFullscreen ? FullscreenMode.borderless : FullscreenMode.windowed;
          notifier.value = notifier.value.copyWith(
            phase: FullscreenPhase.error,
            effectiveMode: actualMode,
            lastError: FullscreenError.stateDesync(
              expected: FullscreenMode.windowed,
              actual: actualMode,
            ),
          );
          _events.add(FullscreenEvent.error(
            error: FullscreenError.stateDesync(
              expected: FullscreenMode.windowed,
              actual: actualMode,
            ),
          ));
          return false;
        }
      }

      return false;
    }
    ```

    **_captureRestoreSnapshot（per D-22）:**
    1. 读取当前 WindowMode（从 WindowBridge.mode.value 或 _driver.isMaximized）
    2. 读取当前位置 `_driver.getPosition()`
    3. 读取当前尺寸 `_driver.getSize()`
    4. 构造 _RestoreSnapshot 存入 `_restoreSnapshots[windowId]`

    **_restoreFromSnapshot（per D-22~D-25）:**
    ```dart
    Future<void> _restoreFromSnapshot(int windowId) async {
      final snapshot = _restoreSnapshots.remove(windowId);
      if (snapshot == null) return;

      // D-23: maximized 恢复采用调用 maximize()
      if (snapshot.isMaximized) {
        await _driver.maximize();
        return;
      }

      // D-24: 副屏恢复采用 setBounds 恢复
      if (snapshot.position != Offset.zero || snapshot.size != Size.zero) {
        try {
          await _driver.setBounds(snapshot.position, snapshot.size);
        } catch (e) {
          // 降级: 副屏不可用时 center
          await _driver.setBounds(null, snapshot.size);
        }
      }
    }
    ```

    **_waitForConfirmation（per D-19 三级回读）:**
    ```dart
    Future<bool> _waitForConfirmation(int windowId, bool expectedFullscreen) async {
      // Level 1: 等待 WindowListener 回调（主路径）
      // 通过订阅 WindowBridge.mode 的变化来检测
      // 如果 500ms 内 mode 变为预期值，返回 true

      // Level 2: 短轮询（100ms 间隔，最多 20 次 = 2s）
      for (int i = 0; i < 20; i++) {
        await Future.delayed(const Duration(milliseconds: 100));
        final actual = await _driver.queryFullscreen();
        if (actual == expectedFullscreen) return true;
      }

      // Level 3: 超时，做一次最终 query() 校正
      return false;
    }
    ```

    **订阅 WindowBridge 回调（per D-07）:**
    构造函数接收 `WindowBridge`，监听其 mode 变化:
    - `mode.value == WindowMode.fullscreen` → 可能是 OS 触发的全屏（forcedChange）
    - 需要区分是我们触发的还是 OS 触发的（通过当前 phase 判断）

    **FullscreenAdapter 抽象接口修改:**
    在 `fullscreen_adapter.dart` 中添加一个可选的 `currentFullscreen` getter 用于 toggle 解析:
    - `bool currentFullscreen(int windowId)` — 从 snapshot 读取当前是否全屏
    - 或者在 FullscreenCommandQueue 的 toggle 解析中直接读取 snapshot

    实际上 toggle 解析应该在 FullscreenCommandQueue 内部完成。需要在 enqueue 时传入当前状态。
    修改 FullscreenCommandQueue: `enqueue` 接受一个 `isCurrentlyFullscreen` 回调参数，toggle 解析时使用。
