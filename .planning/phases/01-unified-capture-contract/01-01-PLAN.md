<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Flutter/runtime/player error → reporter | Exception type, message, stack text, and PlayerError context are untrusted diagnostic payloads. |
| Reporter → effects/listeners | Extension effects and ValueNotifier listeners can throw or recursively invoke reporting. |
| Reporter → future presentation host | A pre-runApp queue crosses to a later UI readiness boundary without synchronous UI work now. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Denial of Service | `ErrorReporterImpl` input snapshots and queue | high | mitigate | Task 2 bounds text/frame snapshots, compares only five queued records, uses capacity five, and burst-tests 100/1000 inputs. |
| T-01-02 | Denial of Service | Effects, listeners, and reentrant reporter calls | high | mitigate | Tasks 1–2 use `_isReporting`, per-effect containment, `try`/`finally`, and a non-recursive fallback with fault-injection tests. |

| T-01-04 | Tampering | Error message/stack used as diagnostic metadata | medium | mitigate | Task 2 stores text as bounded opaque strings and derives only a comparison fingerprint; it does not execute, parse as a filesystem path, or emit commands from payload text. |
