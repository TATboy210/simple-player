<objective>
Delete the dead DesktopFullscreenDriver (window_manager fallback) and DesktopFullscreenDriverFactory (platform detection factory), inline driver creation into WindowService.init() as a static _createDriver() method. Add FullscreenResult sealed class for type-safe error handling. Satisfies FULL-01 (layer reduction 4 to 3) and FULL-02 (evaluation document already exists).

Purpose: Remove two unnecessary abstraction layers that add indirection without value. The factory pattern was designed for multi-driver fallback scenarios that a single-window media player does not need. The DesktopFullscreenDriver (window_manager wrapper) is strictly inferior to the Win32 FFI driver on Windows and is never the right choice.

Output: Simplified bridge layer with 3 files removed, WindowService as direct driver owner, FullscreenResult for error handling.
</objective>
