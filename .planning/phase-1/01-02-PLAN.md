<objective>
Consolidate fullscreen state to a single source of truth (WindowService.mode), remove dead persistence code from SettingsStore/WindowPersistence/AppSettings, simplify resize debounce to single Timer, and simplify confirmation chain from 20x polling to callback + single query. Satisfies FULL-03.

Purpose: Eliminate the dual-state problem where WindowService._isFullscreen and WindowService._state.mode can desync. Remove dead persistence code that saves fullscreen state but never loads it back. Simplify internal Timer and confirmation complexity.

Output: WindowService with single state source, no dead persistence code, simpler timer and confirmation logic.
</objective>
