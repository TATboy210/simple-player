# Plan 01-05: 修复设置面板毛玻璃效果 — 消除嵌套 BackdropFilter

## 背景

Plans 01-01/02/03 将所有 tab 从 SettingsCard 迁移到 GlassContainer，同时把面板外层也换成了 GlassContainer。
这导致了 **双重 BackdropFilter 嵌套**：外层 GlassContainer 模糊一次，tab 内的 GlassContainer 又模糊一次。
加上 bgGlass 的 55% 不透明度，两层叠加后有效不透明度约 80%，毛玻璃效果完全不可见。

## 核心修复思路

**外层去 Glass，内层保留 Glass：**

```
当前结构（错误）:
GlassContainer ← 外层 BackdropFilter + bgGlass(55%)
  ├─ Container(bgGlass) ← 标题栏
  ├─ tab → GlassContainer ← 内层 BackdropFilter + bgGlass(55%)
  └─ Container(bgGlass) ← 底部栏

修复后结构:
ClipRRect ← 仅裁剪圆角
  ├─ Container(bgElevated) ← 标题栏（不透明深色）
  ├─ tab → GlassContainer ← 唯一的 BackdropFilter（清晰可见）
  └─ Container(bgElevated) ← 底部栏（不透明深色）
```

## 失败经验总结

| 之前的错误做法 | 为什么失败 | 正确做法 |
|--------------|----------|---------|
| 外层也用 GlassContainer | 双重 BackdropFilter 嵌套，毛玻璃效果被吃掉 | 外层用 ClipRRect + Container(bgElevated) |
| 标题栏/底部栏用 bgGlass | 55% 不透明色在 BackdropFilter 内部太透明 | 用 bgElevated（完全不透明深色） |
| 每个 tab 的 GlassContainer 有 margin | margin 通过 Padding 包裹，不影响毛玻璃 | 保持不变（这部分是对的） |

## 任务

### Task 1: 修改 settings_panel.dart — 移除外层 GlassContainer

**当前代码问题（settings_panel.dart）:**
- 第 8 行: `import glass_container.dart` — 外层不再需要
- 第 146 行: `GlassContainer` 包裹整个面板 → 双重 BackdropFilter
- 第 160 行: `color: Tokens.bgGlass` → 标题栏太透明
- 第 279 行: `color: Tokens.bgGlass` → 底部栏太透明

**修复步骤:**

1. **移除第 8 行的 glass_container.dart import**（外层不再使用）

2. **替换第 146-234 行的 GlassContainer 为 ClipRRect + Container:**
   ```dart
   ClipRRect(
     borderRadius: BorderRadius.circular(Tokens.radiusLarge),
     child: Container(
       decoration: BoxDecoration(
         color: Tokens.bgElevated,
         borderRadius: BorderRadius.circular(Tokens.radiusLarge),
         border: Border.all(color: Tokens.borderHighlight, width: 1),
       ),
       child: SizedBox(
         width: 600,
         height: 480,
         child: Column(
           children: [
             // ... 标题栏、Divider、内容区、底部栏不变
           ],
         ),
       ),
     ),
   )
   ```

3. **标题栏背景（第 160 行）:** `Tokens.bgGlass` → `Tokens.bgElevated`

4. **底部栏背景（第 279 行）:** `Tokens.bgGlass` → `Tokens.bgElevated`

**验证:**
- `flutter analyze lib/ui/dialogs/settings_panel.dart` 无 warning
- 面板有圆角 + borderHighlight 边框
- 标题栏/底部栏是不透明深色

## 关键决策

| 决策 | 原因 |
|------|------|
| 外层用 bgElevated 而非 bgGlass | 避免在 BackdropFilter 内部使用半透明色导致的双重模糊 |
| 标题栏/底部栏用 bgElevated | 与面板主体背景一致，视觉统一 |
| 保留面板边框 borderHighlight | 微光边框是毛玻璃风格的标志性元素 |
| 保留 tab 内 GlassContainer | 它们是毛玻璃效果的正确位置（单层 BackdropFilter） |

## 风险

| 风险 | 缓解 |
|------|------|
| bgElevated 与 bgPanel 视觉差异太小 | 可调整为 bgPanel 或自定义颜色 |
| 面板边框与 tab 卡片边框视觉重复 | 可移除面板边框，只保留 tab 卡片边框 |
| ClipRRect 不如 GlassContainer 的裁剪精确 | ClipRRect 是标准 Flutter 裁剪，足够用 |
