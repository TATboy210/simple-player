# 故障排除

## 常见问题

### 无法播放文件

**症状**: 打开文件后黑屏，或显示错误提示栏

**可能原因及解决方案**:

1. **文件格式不支持**
   - 确认文件是常见的视频格式（MP4、MKV、AVI、MOV 等）
   - 尝试用其他播放器（如 VLC）确认文件本身可播放

2. **文件损坏**
   - 文件下载不完整或存储介质损坏
   - 尝试重新下载或从备份恢复

3. **编解码器不支持**
   - 某些特殊编码格式可能不被 MDK/FFmpeg 支持
   - 尝试在设置 > 性能中关闭"硬件解码"

4. **路径问题**
   - 文件路径包含特殊字符
   - 文件已被移动或删除
   - 网络路径不可达

**错误类型参考**:

| 错误消息 | 说明 |
|----------|------|
| 文件路径为空 | 未提供有效的文件路径 |
| 文件不存在 | 文件已被移动或删除 |
| 文件路径无效 | 路径包含非法字符或路径遍历尝试 |
| 不支持的媒体格式 | 文件格式不被支持 |
| 无法解码媒体 | 文件编码不被支持或文件损坏 |
| 编解码器不支持 | 特定编解码器不可用 |
| 播放失败 | 播放过程中发生错误 |
| 跳转失败 | 跳转到指定位置失败 |
| 视频渲染失败 | 视频纹理创建失败 |
| 打开超时 | 文件打开超时（可能是网络文件） |
| 网络超时 | 网络连接超时 |
| 连接中断 | 网络连接丢失 |

---

### 画面花屏或绿块

**症状**: 视频播放时出现绿色方块、花屏、色块或画面异常

**解决方案**:

1. 打开设置 > 性能
2. 关闭"硬件解码"
3. 关闭设置面板
4. 重新打开文件

**说明**: 某些 GPU 的硬件解码器对特定编码格式的支持不完善，关闭硬件解码后改用软件解码可以解决。

---

### 画面撕裂

**症状**: 视频画面出现水平撕裂线，通常在快速运动画面时明显

**解决方案**:

1. 打开设置 > 性能
2. 启用"D3D11 CPU 同步"
3. 重新打开文件使设置生效

**说明**: D3D11 CPU 同步确保 CPU 和 GPU 每帧同步，消除撕裂但会略微增加延迟。

---

### 字幕不显示

**症状**: 加载字幕文件后屏幕上没有字幕

**排查步骤**:

1. **确认字幕已加载**: 检查字幕图标是否显示已加载状态
2. **确认字幕未关闭**: 按 `S` 键切换字幕开关
3. **检查字幕延迟**: 字幕延迟可能偏移过大
   - 按 `]` 延迟 500ms
   - 按 `[` 提前 500ms
4. **确认字幕格式**: 支持 .srt、.ass、.ssa、.sub、.vtt 格式
5. **确认字幕编码**: 字幕文件应使用 UTF-8 编码

---

### 没有声音

**症状**: 视频画面正常但没有声音输出

**排查步骤**:

1. **检查播放器静音状态**: 音量图标是否显示静音状态
   - 按 `M` 键取消静音
   - 按 `↑` 键增大音量
2. **检查播放器音量**: 音量滑块是否在 0 位置
   - 拖动音量滑块增大音量
3. **检查系统音量**: Windows 系统音量是否正常
4. **切换音轨**: 打开设置 > 音轨，尝试切换到其他音轨
5. **检查音频输出设备**: 确认 Windows 音频输出设备正确

---

### 播放卡顿

**症状**: 视频播放不流畅，有跳帧、停顿或音画不同步

**解决方案**:

1. **启用硬件解码**: 设置 > 性能 > 硬件解码（开启）
2. **启用 D3D11 CPU 同步**: 设置 > 性能 > D3D11 CPU 同步（开启）
3. **关闭其他 GPU 密集型程序**: 游戏、视频编辑软件等
4. **降低视频质量**: 对于 4K/高码率视频，如果硬件配置不足，可能需要降低播放速度

**系统要求参考**:

| 视频类型 | 最低配置 |
|----------|----------|
| 1080p H.264 | 集成显卡即可 |
| 1080p HEVC | 支持 HEVC 硬解的 GPU |
| 4K H.264 | 独立显卡推荐 |
| 4K HEVC | 支持 HEVC 硬解的独立显卡 |

---

### 快捷键无响应

**症状**: 按下快捷键没有反应

**排查步骤**:

1. **确认窗口焦点**: 播放器窗口必须处于活动状态（标题栏高亮）
2. **检查输入焦点**: 如果焦点在文本输入框上（如设置中的快捷键绑定），键盘事件不会被播放器拦截
3. **检查自定义绑定**: 打开设置 > 快捷键，确认按键绑定是否正确
4. **重置快捷键**: 在设置 > 快捷键中点击"恢复默认"

---

### 窗口大小异常

**症状**: 窗口大小无法调整、显示异常或位置不正确

**解决方案**:

1. **最大化/还原**: 双击标题栏切换
2. **退出全屏**: 按 `ESC` 键
3. **拖拽调整**: 拖拽窗口边缘调整大小
4. **重新启动**: 关闭并重新打开播放器

---

### 导入设置失败

**症状**: 导入设置 JSON 文件时显示错误

**常见错误及解决方案**:

| 错误 | 说明 | 解决方案 |
|------|------|----------|
| 无效 JSON | 文件格式不正确 | 确认文件是有效的 JSON 格式 |
| 无法读取文件 | 文件被占用或权限不足 | 关闭占用文件的程序，或以管理员权限运行 |

---

### 导出设置失败

**症状**: 导出设置时显示"导出失败"

**解决方案**:

1. 确认目标路径有写入权限
2. 确认磁盘空间充足
3. 确认目标文件未被其他程序占用

---

### 播放列表问题

**症状**: 播放列表为空或不显示文件

**解决方案**:

1. **添加文件**: 通过打开文件或拖拽添加视频到播放列表
2. **扫描文件夹**: 右键菜单中选择"扫描文件夹"发现同目录下的其他视频
3. **检查历史**: 切换到历史 Tab 查看播放记录

---

## 错误提示栏

当播放出错时，控制栏上方会显示错误提示栏，提供以下操作：

| 按钮 | 说明 |
|------|------|
| 重新打开 | 尝试重新打开当前文件 |
| 选择其他文件 | 打开文件选择器选择新文件 |
| 重试 | 重试上一次操作 |

---

## 获取帮助

如果以上方法都无法解决问题：

1. **查看日志**: 日志文件位于 `%APPDATA%/com.simpleplayer.app/`
2. **导出调试数据**: 在 Debug 模式下按 `Ctrl+Shift+D` 导出调试数据
3. **提交 Issue**: 在项目仓库提交 Issue，附上错误信息和日志文件

---

## 已知限制

- 硬件解码在部分旧 GPU 上可能不稳定，建议关闭后使用软件解码
- 去隔行功能仅在软件解码器模式下生效
- 性能设置的更改需要重新打开文件才能生效
- 网络流媒体的缓冲机制依赖底层 MDK 引擎，可能在弱网环境下出现卡顿
