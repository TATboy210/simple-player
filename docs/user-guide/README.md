# Simple Player 用户手册

> 版本: 1.0.0-rc.1 | 平台: Windows | 技术栈: Flutter + fvp (MDK/FFmpeg)

Simple Player 是一款暗色主题的桌面媒体播放器，专注于沉浸式视听体验。采用毛玻璃（Glassmorphism）设计语言，支持丰富的键盘快捷键和拖拽交互。

## 1. 安装和配置

### 系统要求

- **操作系统**: Windows 10/11
- **磁盘空间**: 约 100 MB（不含视频文件）
- **运行环境**: 已内置 Flutter 运行时和 MDK/FFmpeg 解码库，无需额外安装

### 安装方式

#### 方式一：MSIX 安装包（推荐）

1. 下载 `SimplePlayer.msix` 安装包
2. 双击运行，按提示完成安装
3. 从开始菜单或桌面快捷方式启动

#### 方式二：从源码构建

```bash
# 克隆仓库
git clone <repository-url>
cd simple_player_flutter

# 安装依赖
flutter pub get

# 运行
flutter run -d windows

# 构建发布版
flutter build windows --release
```

### 首次启动

启动后会看到极光呼吸动画的待机界面，中央显示品牌名 "S I M P L E   P L A Y E R" 和 "打开文件" 按钮。此时播放器处于空闲状态，等待加载媒体文件。

## 2. 界面概览

Simple Player 采用单窗口全屏友好的布局设计，主要由以下部分组成：

```
+--------------------------------------------------+
|  Simple Player     [置顶] [最小化] [最大化] [关闭] |  <-- 标题栏
+--------------------------------------------------+
|                                                    |
|                                                    |
|              视频画面区域                            |  <-- 视频渲染
|                                                    |
|                                                    |
+--------------------------------------------------+
|  [OSD 提示浮层]                                    |  <-- 操作反馈
+--------------------------------------------------+
|  文件名              00:05:30 / 01:30:00           |  <-- 控制栏 Row 1: 标题+时间
|  ████████░░░░░░░░░░░░░░░░░░░░░░░░░░               |  <-- 控制栏 Row 2: 进度条
|  [模式] [音量🔊] [1x倍速]  [⏮][⏪][▶][⏩][⏭][⏹]  [📁][字幕][列表][设置][⛶] |  <-- 控制栏 Row 3: 按钮
+--------------------------------------------------+
```

### 标题栏

- **拖拽**: 按住标题栏拖动可移动窗口
- **双击**: 双击标题栏切换最大化/还原
- **置顶按钮**: 将窗口固定在所有窗口之上
- **最小化/最大化/关闭**: 标准窗口控制

### 控制栏

控制栏位于窗口底部，采用毛玻璃背景。鼠标移入窗口底部 150px 区域时自动显示，静止 3 秒后自动隐藏（全屏模式下）。

控制栏分为三行：

| 行 | 左侧 | 中间 | 右侧 |
|----|-------|------|------|
| Row 1 | 文件名（溢出省略） | 当前时间 / 总时长 | - |
| Row 2 | 进度条（已播放/已缓冲/未播放三层） | | |
| Row 3 | 播放模式、音量、倍速 | 上一首、快退、播放/暂停、快进、下一首、停止 | 打开文件、字幕、播放列表、设置、全屏 |

### OSD 提示浮层

执行操作时（如调节音量、切换倍速），屏幕中上方会短暂显示操作反馈浮层。

## 3. 基本使用

### 3.1 打开文件

有三种方式打开视频文件：

1. **按钮**: 点击控制栏右下角的文件夹图标
2. **快捷键**: 按 `O` 键
3. **拖拽**: 从 Windows 资源管理器直接拖拽文件到播放器窗口

支持的视频格式包括所有 MDK/FFmpeg 支持的格式，常见如：MP4、MKV、AVI、MOV、FLV、WEBM 等。

### 3.2 播放控制

| 操作 | 方法 |
|------|------|
| 播放/暂停 | 点击中央播放按钮 / 按 `空格` 键 |
| 停止 | 点击停止按钮（方形图标） |
| 上一首 | 点击上一首按钮 / 按 `P` 键 |
| 下一首 | 点击下一首按钮 / 按 `N` 键 |
| 快退 10 秒 | 点击快退按钮 / 按 `←` 键（每次 5 秒） |
| 快进 30 秒 | 点击快进按钮 / 按 `→` 键（每次 5 秒） |

### 3.3 进度跳转

- **点击**: 直接点击进度条上任意位置跳转
- **拖拽**: 按住进度条上的滑块拖动，松手后跳转
- **悬停提示**: 鼠标悬停在进度条上时，会显示对应位置的时间标签

进度条使用三层颜色区分：
- **已缓冲**: 较浅的灰色区域
- **已播放**: 主题色（蓝色）区域
- **未播放**: 深灰色背景

### 3.4 音量控制

- **滑块**: 拖动控制栏左侧的音量滑块
- **滚轮**: 在音量滑块上滚动鼠标滚轮，每次调整 5%
- **静音**: 点击音量图标切换静音/取消静音
- **键盘**: 按 `↑` 键增大音量 5%，按 `↓` 键减小音量 5%，按 `M` 键切换静音

音量图标会根据当前音量自动变化：
- 静音或音量为 0: 静音图标
- 音量 < 50%: 低音量图标
- 音量 >= 50%: 高音量图标

### 3.5 播放速度

控制栏左侧的三段式倍速控件（`<` `1x` `>`）：

- **点击左箭头**: 降低速度
- **点击右箭头**: 提高速度
- **双击中间数字**: 重置为 1x
- **滚轮**: 在倍速控件上滚动鼠标滚轮切换档位

可用速度档位: 0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x, 3x, 4x

### 3.6 全屏模式

- **按钮**: 点击控制栏右下角的全屏图标
- **双击**: 在视频画面区域双击切换全屏
- **快捷键**: 按 `F` 键切换（如已绑定）或按 `ESC` 退出全屏

全屏模式下：
- 标题栏自动隐藏
- 控制栏鼠标移入底部时显示，静止后自动隐藏
- 窗口拖拽调整大小功能禁用

### 3.7 字幕

- **加载字幕**: 点击控制栏右侧的字幕图标，选择 `.srt`、`.ass`、`.ssa`、`.sub`、`.vtt` 格式的字幕文件
- **开关字幕**: 按 `S` 键切换字幕显示/隐藏
- **字幕延迟**: 按 `]` 键延迟 500ms，按 `[` 键提前 500ms

字幕设置会自动记忆，下次打开同一文件时自动恢复。

### 3.8 文件拖放

从 Windows 资源管理器直接拖拽视频文件到播放器窗口即可播放。拖入时界面会显示拖拽提示动画。支持同时拖入多个文件，自动加入播放列表。

## 5. 播放列表管理

### 打开播放列表

点击控制栏右侧的播放列表图标（音符图标）打开播放列表面板。

### 布局模式

- **宽屏（>= 600dp）**: 播放列表在右侧与视频并排显示
- **窄屏（< 600dp）**: 播放列表以浮窗形式叠加在视频上方

### 双 Tab 设计

播放列表面板包含两个标签页：

#### 文件夹 Tab

- 显示当前播放列表中的文件
- 按文件夹分组展示缩略图
- 支持扫描文件夹中的其他视频文件
- 右键菜单：播放、继续播放（从上次断点）、复制路径、属性、移除、打开文件所在目录、扫描文件夹

#### 历史 Tab

- 按时间排序的播放历史记录
- 显示最后播放时间和断点位置
- 支持继续播放（从断点恢复）
- 右键菜单：播放、继续播放、复制路径、属性、移除、打开文件所在目录、清空历史

### 播放模式

点击控制栏左侧的播放模式图标循环切换：

| 模式 | 图标 | 说明 |
|------|------|------|
| 顺序播放 | 重复图标 | 按列表顺序播放，播完后循环 |
| 单曲循环 | 重复图标（标记 1） | 当前曲目循环播放 |
| 随机播放 | 随机图标 | 随机顺序播放 |

### 关闭播放列表

- 点击播放列表外部区域
- 按 `ESC` 键
- 再次点击播放列表图标

- **恢复默认**: 将当前标签页的设置重置为默认值

- **导出**: 将所有设置导出为 JSON 文件

## 7. 故障排除

### 无法播放文件

**症状**: 打开文件后黑屏或显示错误

**解决方案**:
1. 确认文件格式是否支持（MP4、MKV、AVI、MOV 等常见格式均可）
2. 检查文件是否损坏（尝试用其他播放器打开）
3. 如果使用硬件解码，尝试在设置 > 性能中关闭"硬件解码"
4. 查看错误提示栏，点击"重试"或"选择其他文件"

### 画面花屏或绿块

**症状**: 视频播放时出现绿色方块、花屏或色块

**解决方案**:
1. 打开设置 > 性能 > 关闭"硬件解码"
2. 关闭后重新打开文件

### 画面撕裂

**症状**: 视频画面出现水平撕裂线

**解决方案**:
1. 打开设置 > 性能 > 启用"D3D11 CPU 同步"
2. 重新打开文件使设置生效

### 字幕不显示

**症状**: 加载字幕后字幕不显示

**解决方案**:
1. 确认字幕格式正确（支持 .srt、.ass、.ssa、.sub、.vtt）
2. 按 `S` 键确认字幕未被关闭
3. 检查字幕延迟是否偏移过大（按 `[` 或 `]` 调整）

### 没有声音

**症状**: 视频画面正常但没有声音

**解决方案**:
1. 检查是否被静音（音量图标是否显示静音状态）
2. 按 `M` 键取消静音
3. 按 `↑` 键增大音量
4. 检查系统音量是否正常
5. 尝试在设置 > 音轨中切换音轨

### 播放卡顿

**症状**: 视频播放不流畅，有跳帧或停顿

**解决方案**:
1. 确认硬件解码已开启（设置 > 性能 > 硬件解码）
2. 确认 D3D11 CPU 同步已开启
3. 关闭其他占用 GPU 的程序
4. 对于 4K/高码率视频，确保硬件配置满足要求

### 快捷键无响应

**症状**: 按下快捷键没有反应

**解决方案**:
1. 确认播放器窗口处于活动状态（焦点在播放器上）
2. 如果焦点在文本输入框上（如设置中的快捷键绑定），快捷键会被忽略
3. 检查设置 > 快捷键中是否有自定义绑定冲突

### 窗口大小异常

**症状**: 窗口大小无法调整或显示异常

**解决方案**:
1. 双击标题栏切换最大化/还原
2. 如果处于全屏模式，按 `ESC` 退出
3. 尝试拖拽窗口边缘调整大小

### 导入/导出设置失败

**症状**: 导入或导出设置文件时出错

**解决方案**:
1. 导出：确认目标路径有写入权限且磁盘空间充足
2. 导入：确认文件是有效的 JSON 格式且由 Simple Player 导出
3. 检查文件是否被其他程序占用
