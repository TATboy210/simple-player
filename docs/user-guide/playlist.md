# 播放列表管理

## 打开播放列表

点击控制栏右侧的播放列表图标（音符图标 🎵）打开播放列表浮窗面板。

## 布局模式

Simple Player 会根据窗口宽度自动选择布局模式：

| 条件 | 布局 | 说明 |
|------|------|------|
| 窗口宽度 >= 600dp | 并排布局 | 视频在左，播放列表在右侧 |
| 窗口宽度 < 600dp | 叠加布局 | 播放列表以浮窗形式叠加在视频上方 |

## 播放列表面板

面板采用毛玻璃背景，从底部滑入动画。结构如下：

```
+------------------------------------------+
|  [文件夹]  [历史]          ← Tab 切换    |
|  ───────────────────────── 光条分隔线    |
|                                          |
|  [缩略图1] [缩略图2] [缩略图3] ...      |  ← 水平缩略图列表
|                                          |
+------------------------------------------+
```

### 关闭面板

- 点击面板外部的透明区域
- 按 `ESC` 键
- 再次点击播放列表图标

## 文件夹 Tab

文件夹 Tab 按文件夹分组展示视频缩略图。

### 功能

- **播放**: 点击缩略图直接播放该文件
- **移除**: 从播放列表中移除选中的文件
- **扫描文件夹**: 右键选择"扫描文件夹"，自动发现同目录下的其他视频文件
- **文件属性**: 右键选择"属性"，查看文件的详细信息（分辨率、编码、时长等）

### 右键菜单

| 菜单项 | 说明 |
|--------|------|
| 播放 | 立即播放选中的文件 |
| 继续播放 | 从上次播放的断点位置继续 |
| 复制路径 | 复制文件的完整路径到剪贴板 |
| 属性 | 打开文件属性对话框 |
| 移除 | 从播放列表中移除 |
| 打开文件所在目录 | 在资源管理器中打开文件所在文件夹 |
| 扫描文件夹 | 扫描文件所在目录的其他视频文件 |

## 历史 Tab

历史 Tab 按时间排序显示播放历史记录。

### 功能

- **时间排序**: 最近播放的文件排在最前面
- **断点记忆**: 显示上次播放到的时间位置
- **相对时间**: 显示"刚刚"、"5分钟前"、"2小时前"、"3天前"等相对时间
- **继续播放**: 从断点位置继续播放

### 右键菜单

| 菜单项 | 说明 |
|--------|------|
| 播放 | 从头开始播放 |
| 继续播放 | 从上次断点位置继续 |
| 复制路径 | 复制文件路径到剪贴板 |
| 属性 | 查看文件属性 |
| 移除 | 从历史记录中移除 |
| 打开文件所在目录 | 在资源管理器中打开 |
| 清空历史 | 清除所有播放历史记录 |

## 播放模式

点击控制栏左侧的播放模式图标循环切换三种模式：

### 顺序播放（默认）

- 按列表顺序依次播放
- 播放完最后一首后回到第一首继续循环
- 图标: 标准重复图标

### 单曲循环

- 当前曲目播放完毕后自动从头重新播放
- 图标: 带数字 "1" 标记的重复图标

### 随机播放

- 随机选择下一首要播放的曲目
- 图标: 随机播放图标

## 拖拽添加文件

从 Windows 资源管理器拖拽文件到播放器窗口：
- 单个文件: 直接开始播放
- 多个文件: 全部加入播放列表，播放第一个文件

拖拽时会显示视觉提示，松开后自动开始播放。

## 播放列表持久化

播放列表数据会自动保存到本地存储，包括：
- 文件列表
- 当前播放位置
- 每个文件的播放进度（断点位置）
- 播放模式偏好
- 字幕轨道偏好
- 字幕延迟设置

下次启动播放器时自动恢复上次的播放状态。
