# 设置选项

## 打开设置

点击控制栏右侧的齿轮图标（⚙）打开设置面板。

也可以右键点击齿轮图标打开（预留功能扩展）。

## 设置面板概览

设置面板采用毛玻璃风格的可拖拽对话框，左侧为侧边栏导航，右侧为内容区域。

```
+------------------------------------------------------------------+
|  设置                                        [拖拽指示器] [关闭]  |
+--------+---------------------------------------------------------+
| [通用]  |                                                         |
| [均衡器]|           内容区域                                       |
| [音轨]  |           （根据选中的标签页显示）                        |
| [画面]  |                                                         |
| [快捷键]|                                                         |
| [关于]  |                                                         |
| [性能]  |                                                         |
+--------+---------------------------------------------------------+
|  [恢复默认]        [导入] [导出] | [确定] [取消] [应用]           |
+------------------------------------------------------------------+
```

### 面板操作

| 操作 | 方法 |
|------|------|
| 移动面板 | 按住标题栏拖动（全屏模式下禁用拖拽） |
| 切换标签页 | 点击左侧侧边栏的标签 |
| 关闭面板 | 点击关闭按钮 / 按 ESC / 点击遮罩区域 |

### 底部按钮

| 按钮 | 说明 |
|------|------|
| 恢复默认 | 将当前标签页的设置重置为默认值（需确认） |
| 导入 | 从 JSON 文件导入设置 |
| 导出 | 将所有设置导出为 JSON 文件 |
| 确定 | 保存更改并关闭面板 |
| 取消 | 放弃所有更改并关闭面板 |
| 应用 | 保存更改但不关闭面板 |

> **延迟应用机制**: 语言和主题的更改不会立即生效，而是暂存为"待定值"。点击"确定"或"应用"后才会真正应用。点击"取消"会恢复到打开面板前的状态。这是为了避免语言/主题切换导致 MaterialApp 重建，从而丢失设置面板的对话框状态。

## 通用设置

### 语言

| 选项 | 语言代码 | 说明 |
|------|----------|------|
| 中文 | zh | 简体中文界面 |
| English | en | 英文界面 |

语言设置影响所有 UI 文本、按钮标签、提示信息、错误消息等。

### 主题

| 主题 | 说明 | 主色调 |
|------|------|--------|
| 午夜 (Midnight) | 深蓝色主题（默认） | 蓝色 |
| 海洋 (Ocean) | 青色主题 | 青色 |
| 森林 (Forest) | 绿色主题 | 绿色 |

主题切换影响所有 UI 元素的强调色（accent color）。

## 均衡器

音频均衡器提供预设模式，应用不同的频率响应曲线。

| 预设 | 说明 | 适用场景 |
|------|------|----------|
| 关闭 | 不应用均衡器 | 默认状态 |
| 低音增强 | 增强低频响应 | 电子音乐、嘻哈、电影爆炸场景 |
| 人声增强 | 增强人声频段 | 播客、有声书、人声为主的音乐 |
| 摇滚 | 摇滚风格均衡 | 摇滚、金属音乐 |
| 古典 | 古典音乐均衡 | 古典音乐、交响乐 |

## 音轨

显示当前视频中所有可用的音轨。适用于包含多音轨的视频文件（如多语言电影）。

- 点击音轨名称切换
- 当前激活的音轨会高亮显示
- 音轨选择会自动记忆

## 画面处理

### 色彩校正

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 亮度 (Brightness) | -1.0 ~ 1.0 | 0.0 | 调整画面整体亮度 |
| 对比度 (Contrast) | -1.0 ~ 1.0 | 0.0 | 调整明暗对比度 |
| 饱和度 (Saturation) | -1.0 ~ 1.0 | 0.0 | 调整色彩鲜艳程度 |
| 色调 (Hue) | -180 ~ 180 | 0.0 | 调整色相偏移角度 |

- 0.0 = 无变化（原始值）
- 负值 = 降低 / 减弱
- 正值 = 增强 / 增大

### 旋转

支持四档旋转：

| 角度 | 说明 |
|------|------|
| 0° | 不旋转（默认） |
| 90° | 顺时针旋转 90° |
| 180° | 旋转 180°（上下颠倒） |
| 270° | 顺时针旋转 270°（逆时针 90°） |

### 宽高比

| 模式 | 说明 |
|------|------|
| 原始 (Original) | 保持视频原始宽高比 |
| 拉伸 (Stretch) | 拉伸至填满窗口，可能变形 |
| 裁剪填充 (Crop Fill) | 等比缩放并裁剪多余部分以填满窗口 |
| 自由 (Free) | 不约束宽高比 |

### 去隔行

- **启用去隔行**: 对隔行扫描的视频源进行去隔行处理
- 仅在软件解码器模式下生效
- 适用于旧式电视录制、DVD 等隔行扫描源

## 快捷键

查看和自定义所有键盘快捷键。

### 自定义绑定

1. 点击要修改的快捷键行
2. 行变为"请按下新按键..."的输入状态
3. 按下新的按键
4. 系统自动检测冲突：
   - 无冲突：绑定成功
   - 有冲突：显示"按键已被占用"提示
5. 点击"确定"或"应用"保存

### 恢复默认

点击"恢复默认"按钮，清除所有自定义绑定，恢复为默认按键映射。

## 性能

### D3D11 渲染

**D3D11 CPU 同步**

| 状态 | 说明 |
|------|------|
| 开启（默认） | 每帧同步 CPU 和 GPU，画面稳定但延迟略高 |
| 关闭 | 降低延迟，但可能导致画面撕裂 |

### 解码器

**硬件解码**

| 状态 | 说明 |
|------|------|
| 开启（默认） | 使用 GPU 进行视频解码，CPU 占用低 |
| 关闭 | 使用纯软件解码，适用于硬件解码异常的情况 |

> **重要**: 性能设置的更改在下次打开文件时生效。已打开的文件不会受到影响。

## 设置导入/导出

### 导出设置

1. 点击底部的"导出"按钮
2. 选择保存位置
3. 文件名默认为 `settings_YYYY-MM-DD.json`
4. 导出成功后显示 OSD 提示"设置已导出"

导出的 JSON 文件包含所有可配置的设置项。

### 导入设置

1. 点击底部的"导入"按钮
2. 选择 JSON 设置文件
3. 系统验证文件格式
4. 弹出确认对话框，显示将被覆盖的设置类别：
   - 播放、视频效果、字幕、窗口、快捷键、主题、语言
5. 确认后立即应用所有设置
6. 面板保持打开状态，UI 实时更新

导入失败时会显示详细的错误信息。

## 恢复默认设置

每个可重置的标签页底部都有"恢复默认"按钮，点击后会显示确认对话框，列出将被重置的设置项：

| 标签页 | 重置内容 |
|--------|----------|
| 通用 | 语言、主题 |
| 均衡器 | 均衡器预设 |
| 画面 | 亮度、对比度、饱和度、色调、旋转、宽高比、去隔行 |
| 快捷键 | 自定义快捷键绑定 |
| 性能 | D3D11 CPU 同步、硬件解码 |

> **注意**: 音轨和关于标签页不支持重置。
