# 快捷键说明

## 查看快捷键

在播放器中按 `F1` 或 `?` 键，会弹出快捷键帮助对话框，显示所有可用的快捷键及其功能说明。

## 完整快捷键列表

### 播放控制

| 快捷键 | 功能 | 默认按键 |
|--------|------|----------|
| `Space` | 播放 / 暂停 | Space |
| `←` | 后退 5 秒 | ArrowLeft |
| `→` | 前进 5 秒 | ArrowRight |
| `N` | 下一首 | KeyN |
| `P` | 上一首 | KeyP |

### 音量控制

| 快捷键 | 功能 | 默认按键 |
|--------|------|----------|
| `↑` | 音量增大 5% | ArrowUp |
| `↓` | 音量减小 5% | ArrowDown |
| `M` | 静音切换 | KeyM |

### 字幕控制

| 快捷键 | 功能 | 默认按键 |
|--------|------|----------|
| `S` | 字幕开关 | KeyS |
| `]` | 字幕延迟 +500ms | BracketRight |
| `[` | 字幕延迟 -500ms | BracketLeft |

### 窗口控制

| 快捷键 | 功能 | 默认按键 |
|--------|------|----------|
| `ESC` | 退出全屏 / 关闭播放列表 / 关闭设置面板 | Escape |
| `F1` | 显示快捷键帮助 | F1 |
| `?` | 显示快捷键帮助 | Slash (character '?') |

### 文件操作

| 快捷键 | 功能 | 默认按键 |
|--------|------|----------|
| `O` | 打开文件 | KeyO |

### 媒体键（不可自定义）

| 快捷键 | 功能 |
|--------|------|
| 媒体播放/暂停 | 播放 / 暂停 |
| 媒体下一曲 | 下一首 |
| 媒体上一曲 | 上一首 |

### 调试快捷键（仅 Debug 模式）

| 快捷键 | 功能 |
|--------|------|
| `F12` | 导出性能统计到日志 |
| `Ctrl+Shift+D` | 导出全部调试数据到文件 |

## 自定义快捷键

### 设置方法

1. 打开设置面板（点击齿轮图标）
2. 切换到"快捷键"标签页
3. 点击要修改的快捷键行
4. 按下新的按键
5. 系统会自动检测冲突（如果新按键已被其他操作占用，会显示"按键已被占用"提示）
6. 点击"确定"或"应用"保存

### 重置为默认

在快捷键标签页底部点击"恢复默认"按钮，会清除所有自定义绑定，恢复为默认按键。

### 注意事项

- 自定义绑定存储在本地设置中，支持导入/导出
- 媒体键（播放/暂停、上一曲、下一曲）始终为硬编码，不可自定义
- 当焦点在文本输入框上时（如设置中的快捷键绑定输入），键盘事件不会被播放器拦截
- ESC 键在播放列表面板和设置面板打开时会优先关闭面板，而非退出全屏
