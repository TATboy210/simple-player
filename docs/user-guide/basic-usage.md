# 基本使用

## 打开文件

### 方式一：按钮打开

点击控制栏右下角的文件夹图标（或在待机界面点击"打开文件"按钮），在弹出的文件选择器中选择视频文件。

### 方式二：快捷键

按 `O` 键打开文件选择器。

### 方式三：拖拽

从 Windows 资源管理器直接拖拽一个或多个视频文件到播放器窗口。拖入时界面会显示拖拽提示动画（"拖拽视频至窗口松开即可播放"），松开后开始播放。

> **安全提示**: 拖拽的文件会经过路径验证（长度检查、空字节检查、合法字符验证），无效路径会被自动过滤。

## 播放控制

### 播放/暂停

- 点击控制栏中央的播放/暂停按钮
- 按 `空格` 键
- 按键盘上的媒体播放/暂停键

播放状态下按钮显示为暂停图标（蓝色高亮），暂停状态下显示为播放图标（白色）。

### 停止

点击控制栏中央的停止按钮（方形图标）。停止后回到待机界面。

### 上一首/下一首

- 点击控制栏中央的上一首/下一首按钮
- 按 `P` 键（上一首）/ `N` 键（下一首）
- 按键盘上的媒体上一曲/下一曲键

### 快退/快进

- **快退**: 点击快退按钮（⏪）或按 `←` 键，每次后退 5 秒
- **快进**: 点击快进按钮（⏩）或按 `→` 键，每次前进 5 秒
- **快退 10 秒**: 点击快退 10 秒按钮（⏪ 带数字标记）
- **快进 30 秒**: 点击快进 30 秒按钮（⏩ 带数字标记）

快退/快进操作会显示 OSD 提示浮层，反馈当前播放位置。

## 进度跳转

### 点击跳转

直接点击进度条上任意位置，立即跳转到对应时间点。

### 拖拽跳转

1. 按住进度条上的滑块（白色矩形 thumb）
2. 拖动到目标位置（进度条会实时更新，但引擎采用 100ms 节流以避免性能问题）
3. 松开鼠标完成跳转

拖拽时进度条会略微变粗（3dp -> 5dp），并显示目标位置的时间标签。

### 悬停提示

鼠标悬停在进度条上时，会在光标位置上方显示对应时间的标签。标签使用等宽数字字体，确保数字对齐。

### 进度条三层结构

| 层 | 颜色 | 说明 |
|----|------|------|
| 背景层 | 深灰色 | 整个视频时长 |
| 缓冲层 | 较浅灰色 | 已缓冲的数据范围 |
| 已播放层 | 主题色（蓝色） | 当前已播放的进度 |

## 音量控制

### 滑块调节

拖动控制栏左侧的音量滑块（水平条），范围 0% ~ 100%。

拖拽期间采用 100ms 节流，松手时立即同步最终值（零感知延迟）。

### 滚轮调节

在音量滑块区域滚动鼠标滚轮：
- 向上滚动：音量增大 5%
- 向下滚动：音量减小 5%

滚轮操作无节流（离散事件，每秒约 3-5 次）。

### 静音切换

- 点击音量图标切换静音/取消静音
- 按 `M` 键切换静音
- 按 `↑` / `↓` 键调整音量

静音时音量图标变为带斜线的静音图标，按钮高亮为主题色。取消静音时恢复到静音前的音量。

**智能静音恢复**: 在静音状态下拖动滑块到非零值，会自动取消静音。

### 音量图标变化

| 状态 | 图标 |
|------|------|
| 静音或音量为 0 | 🔇 静音图标 |
| 音量 < 50% | 🔉 低音量图标 |
| 音量 >= 50% | 🔊 高音量图标 |

## 播放速度

### 三段式倍速控件

控件位于控制栏左侧，由三部分组成：`<` `1x` `>`

| 操作 | 方法 |
|------|------|
| 降低速度 | 点击左箭头 `<` |
| 提高速度 | 点击右箭头 `>` |
| 重置为 1x | 双击中间数字 |
| 切换档位 | 在控件上滚动鼠标滚轮 |

### 可用速度档位

| 档位 | 说明 |
|------|------|
| 0.5x | 半速播放 |
| 0.75x | 稍慢 |
| 1.0x | 正常速度（默认） |
| 1.25x | 稍快 |
| 1.5x | 1.5 倍速 |
| 2.0x | 2 倍速 |
| 3.0x | 3 倍速 |
| 4.0x | 4 倍速 |

切换倍速时会显示 OSD 提示（如 "1.5x"）。

## 全屏模式

### 进入全屏

- 点击控制栏右下角的全屏图标
- 在视频画面区域双击
- 按 `F` 键（如已绑定）

### 退出全屏

- 按 `ESC` 键
- 在视频画面区域双击
- 按 `F` 键（如已绑定）

### 全屏模式下的行为

- 标题栏完全透明且不可交互
- 控制栏鼠标移入窗口底部 150px 区域时显示，鼠标静止后自动隐藏
- 窗口拖拽调整大小功能禁用
- 鼠标光标恢复为默认样式

## 字幕

### 加载字幕

点击控制栏右侧的字幕图标（CC），选择字幕文件。

支持的字幕格式：
- `.srt` — SubRip 字幕
- `.ass` — Advanced SubStation Alpha
- `.ssa` — SubStation Alpha
- `.sub` — MicroDVD 字幕
- `.vtt` — WebVTT 字幕

### 字幕开关

按 `S` 键切换字幕显示/隐藏。字幕开关状态会自动记忆。

### 字幕延迟调整

- 按 `]` 键：字幕延迟增加 500ms（字幕往后推）
- 按 `[` 键：字幕延迟减少 500ms（字幕往前推）

字幕延迟设置会自动记忆，下次打开同一文件时自动恢复。

## 媒体键支持

Simple Player 支持键盘上的媒体控制键：

| 媒体键 | 功能 |
|--------|------|
| 播放/暂停 | 切换播放/暂停 |
| 下一曲 | 下一首 |
| 上一曲 | 上一首 |

媒体键始终为硬编码绑定，不支持自定义。
