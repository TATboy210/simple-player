# Wave 4 Plan 03: Path Provider Migration — Log Directory

## Objective

将 `log.dart` 中硬编码的 `%APPDATA%` 路径迁移到 `path_provider` 包，使日志目录在所有平台上正确解析。

**Purpose:** 消除 Windows 特定的路径假设，为 macOS/Linux 移植做准备。
**Output:** `initLog()` 使用 `getApplicationSupportDirectory()` 获取跨平台日志目录。

## Context

当前状态:
- `log.dart` 第 148 行: `final appData = Platform.environment['APPDATA'];`
- 使用 `%APPDATA%\SimplePlayer\logs\` 作为日志目录
- 路径分隔符硬编码为 `\\`（Windows）
- `PlaylistStore` 已经使用 `getApplicationSupportDirectory()`（跨平台）
- `SettingsStore` 使用 `shared_preferences`（跨平台）

关键约束:
- `initLog()` 是 `async` 方法，可以 await `getApplicationSupportDirectory()`
- `path_provider` 已在 `pubspec.yaml` 中（`^2.1.5`）
- 需要保持日志文件路径向后兼容（或处理迁移）

## Tasks

### Task 1: initLog() 使用 path_provider

**文件:**
- `lib/kernel/utils/log.dart`
- `test/kernel/utils/log_test.dart`

**Action:**
将 `initLog()` 中的 `%APPDATA%` 硬编码路径改为 `getApplicationSupportDirectory()`:

1. 修改 `lib/kernel/utils/log.dart`:
   - 添加导入: `import 'package:path_provider/path_provider.dart';`
   - 移除 `import 'dart:io';` 中对 `Platform.environment` 的使用（保留 `dart:io` 用于 `Directory`/`File`）
   - 修改 `initLog()` 方法:
     ```dart
     Future<void> initLog() async {
       if (kDebugMode) return;

       try {
         final appDir = await getApplicationSupportDirectory();
         final dir = Directory('${appDir.path}${Platform.pathSeparator}logs');
         if (!dir.existsSync()) {
           dir.createSync(recursive: true);
         }
         // ... 其余逻辑不变，但路径分隔符使用 Platform.pathSeparator
       } on Exception catch (e) {
         debugPrint('[Log] file logging init failed: $e');
       }
     }
     ```
   - 更新 `_RotatingFileOutput` 中的路径构建:
     - `'${dir.path}\\app_$timestamp.log'` 改为 `'${dir.path}${Platform.pathSeparator}app_$timestamp.log'`
     - 同样处理 `_rotate()` 和 `_cleanupArchives()` 中的路径

2. 更新 `test/kernel/utils/log_test.dart`:
   - 如有测试 `initLog()`，需要 mock `getApplicationSupportDirectory()`
   - 或者跳过（`initLog()` 在 debug 模式下是 no-op）

3. 更新文件顶部注释:
   - `/// Logs are written to '%APPDATA%\SimplePlayer\logs\'` 改为 `/// Logs are written to application support directory /logs/`

**Verify:**
```bash
flutter test test/kernel/utils/log_test.dart
flutter analyze
```

**Done:**
- `initLog()` 使用 `getApplicationSupportDirectory()` 获取日志目录
- 路径分隔符使用 `Platform.pathSeparator`（跨平台）
- `flutter analyze` 零警告
- 测试通过
